# Yunzai 到独立 Core 的迁移核对

比对基线为旧宿主停写后的 2026-11-18 冻结备份，包含旧配置与应用数据归档、Redis RDB、NapCat 配置及服务定义。线上版本核对以实际进程和发行清单为准。当前迁移工作树承接了生产版本 83e0755 中的群学习超时修复。

| 内容 | 迁移核对 |
| --- | --- |
| 创作工作台 | 独立控制台使用生产的 3 个生图渠道和 2 个编辑渠道。旧目录的 100 张成图及 100 份参数记录已导入，浏览器已实际显示历史图片。生成、编辑、取消和多图历史由隔离模型夹具与真实 HTTP 回归覆盖。 |
| 游戏 | 线上读回海龟汤 11 道题、25 道候选题及对应的 Core 管理接口。此前核对 7 局旧对局和 7 名赛马娘玩家的积分已迁入。独立控制台写入题库所属机器人和账号的分区。 |
| 表达学习 | 已导入 24 条旧规则和 13 个群的词库。控制台可修剪归档规则和屏蔽归档词汇。Core 的按人发言风格读取使用现有的来源授权。旧全局自动总结和旧群词库的运行时注入仍缺接线。 |
| 记忆检索 | 旧配置的 embedding 渠道通过真实中性输入返回 1024 维向量。生产已启用群聊语义召回，沿用旧模型、30 天保留期和群聊范围。22 个群的历史语义文件及旧评估已导入，共 52,617 个历史语义块。源块缺少逐条作者归属时，现有遗忘状态限制控制台读取和模型使用。 |
| 用量 | 执行离线账本导入后，从 22 个历史日文件恢复 35,410 条调用或归组记录。导入按原记录匹配并保留当前 Core 记录。 |
| 其余文件资料 | 旧应用数据的 170 个文件、353,393,273 字节已复制到 Core 的私有 legacy-source 目录，逐文件记录 SHA-256。覆盖原消息归档、骰子状态和团录、情节、人物反馈、表达观察、群管素材、调用追踪和原群名缓存。配置和原 Redis 快照保留在冻结备份。 |
| 活跃消息及记忆 | 冻结原文覆盖 12 个群、16,117 条记录。15,598 条原事件 ID 包含经核对的接收 QQ。15,587 条同时符合旧白名单、人设映射、当前群绑定和保留期。其中 9,689 条为初筛的完整顶层文本候选。正式计数依照两端隐私、撤回、策略和容量扣除。此前已按出处导入 4 条长期记忆及 8 条必要回执。 |
| QQ 及旧后台剩余差异 | 主 QQ 已在 Core 接入并认证。另两只旧 NapCat 容器仍需在 QQ 端重新认证，完成后须按原账号证据确认连接与会话绑定。旧入群验证、欢迎退群、模型探测、QQ 空间发布及容器管理入口仍有功能差异。 |

导入工具为 scripts/import-legacy-console-resources.py、scripts/import-legacy-token-usage.py 和 scripts/archive-legacy-data.py。三个工具默认预演，显式 --apply 后写入。原始备份作为后续逐项对照的来源。

群原文由独立 Core 的 `--migrate-legacy-group-archive --backup-dir <冻结备份> --connection qq-main` 预演。导入需停止目标 Core 并等待 Redis 租约释放后添加 `--apply`。只使用冻结归档中的完整顶层原文，逐组原子登记原文、人物来源与启用的语义来源。历史和语义各自遵循保留期和容量，优先装入最近的合格旧消息；导入命令不产生向量或模型答复。

切换至 8e0b746 后发现独立宿主对历史图片的二进制响应直接调用文本凭据检查，引发请求失败。生产回读随即触发回切。后续发布修正了响应类型转换并增加完整 CLI 图片回归，使用实际图片字节验证成功，注入测试凭据的图片经 HTTP 拒绝。

生产版本 0feb17a 的服务器回执保存在 staging/console-resources-0feb17a-zi8ru7lm/production-verification.log。已校验 789 个发行文件，Linux 定向测试整批 86 项通过，另有真实 CLI 图片认证回归通过，并从 Chrome 打开资源库及四个资源页。完整控制台 CLI 的一个旧用例在候选和前一个生产版本都存在同一断言失败，单独保留旧基线证据。
