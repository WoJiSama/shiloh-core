# 安全基线与威胁模型（SECURITY BASELINE）

> 维护规则：**改动了任何一条边界所描述的代码，必须在同一个提交里更新本文对应条目。**
> 发布前检查清单见文末。最后全面复核：2026-10-26。
> 自主角色相关边界更新：2026-11-11，依据本地实现核对；实际发布与验收证据见自主角色路线文档第 12.14 节。

## 一、威胁模型

| 主体 | 能力假设 | 主要防线 |
| --- | --- | --- |
| **QQ 群友**（含陌生群成员） | 可发任意文本/图片/表情/戳一戳；可诱导模型（prompt injection）；可刷屏 | 群白名单、工具面裁剪、发送白名单（仿真工具目标绑定会话群）、出站脱敏与审查、频率限制 |
| **被注入的模型**（上游返回被诱导的输出） | 可尝试输出内部路径/凭据/工具参数 JSON；可尝试在仿真回合越权发送或借群友身份执行 | internalStatusLeak 出站脱敏（含凭据形状）、工具参数 JSON 拦截、发送配额与冷却、执行主体校验；文本兜底同样经过工具执行与发送边界 |
| **控制台用户** | 拿到控制台访问权后可改配置、看统计、管理仿真 | scrypt 账密 + 长令牌、revision 乐观锁、建议绑定 127.0.0.1/内网、凭据脱敏读写 |
| **同机其他进程/用户** | 可读插件目录与 Redis | Redis 由 TRSS 宿主管理；config 明文 key 的残余风险见 R2 |
| **MCP server / custom_tools**（第三方扩展） | 任意代码执行能力（stdio 子进程/热加载 JS） | 仅 master 手工部署；不随包分发；工具结果截断 8000 字符 |
| **上游 provider**（LLM/搜索/embedding/VLM） | 收到发过去的全部内容 | 见「数据出机清单」，逐项可关 |

明确**不防**：腾讯侧风控（靠出站节流降低概率）、宿主机被完全攻破、上游 provider 滥用数据。

## 二、已实现边界（按攻击面）

1. **准入**：群白名单 `enableGroupWhitelist/allowedGroups`（默认开）；用户黑名单；私聊白名单（空=仅主人）；`#` 命令与仿真流互斥；违禁词命中即中断该群进行中回合（入站+出站双向）。
   - QQ 会话绑定由宿主事件的账号和会话以及本地 `agent-bindings.yaml` 解析，账号矛盾时拒绝聊天回合。绑定只选择角色和人设，准入及工具权限仍由既有策略控制。显式角色使用保留的角色状态前缀，两个 QQ 入口均拒绝与旧人设 ID 冲突的绑定。
   - 旧版 Yunzai 与 OneBot 撤回通知均按账号、会话和完整消息 ID 处理人物记忆。原通知账号冲突时不入队，缺失时仅使用宿主能确定的唯一 QQ 账号。归档关闭和当前角色不可解析时仍可撤回该账号已记录的来源。
   - 普通聊天和仿真从 QQ 适配器读取统一的正文、点名、引用和附件。会话账号及目标来自宿主事件，引用只提供被引用消息的上下文。
2. **工具面**：
   - 主链路：`oneapi_tools` 全局白名单 + 按消息意图过滤 + 路由锁（toolScopeLocked）；私聊默认零工具（仅表情可开）。
   - 仿真回合：装配期只挂本轮仿真/角色工具和 `toolPolicy` 解析出的额外工具。默认 `open` 采用内置普通工具面、全局/按群 deny 做减法；RESTRICTED 敏感工具须显式 allow，自定义工具须显式 extra 放通。未装配的工具不可调用，已装配仍须通过执行主体检查。
   - 执行主体：仅 `atMention/nameMention/question/continuation/session` 的 `reason.seq` 对应真实消息可形成 `user` 主体，并传该消息的用户身份；其余唤醒不回退最近群友。自主目标与 `commitment` 唤醒均不传借来的 `user_id/sender`，主体标签也不替代工具自身授权。
   - 自主/承诺唤醒的运行期工具面仅限本轮创建的仿真/角色/活动工具实例（排除 `simQzoneInteract/simSendPoke/simUpdateAffinity`）、已放通的 `searchInformationTool/webParserTool`，以及 `simulation.autonomousTools` 显式授权且被当前普通策略装配的三个内置图像工具（`bananaTool/googleImageEditTool/googleImageAnalysisTool`）。自定义工具即使取 `sim` 前缀也不因此获权。执行前复核群开关、人设归属、角色暂停、目标状态、共享指纹和活动版本；取消可阻止后续调用，已发起的外部动作不能承诺撤销。
   - 仿真发送工具参数无群号：目标绑定会话群，不存在"发到别的群"的路径；每回合 ≤5 条 + 每分钟 ≤8 条 + 出站令牌桶三重限速。
   - MCP：`config/mcp-servers.yaml` 手工声明，工具结果截断；custom_tools 同理。
3. **出站内容**：
   - 仿真发送先净化整个批次并检查剩余配额，再逐条复核权限/配额；同回合按完整正文精确去重，覆盖文本、引用/@混合消息与工具回复。每条确认成功后先保存预算，再发下一条；传输结果不明时记 unknown 并阻止本回合后续发送。净化/配额预检失败没有外发；真实传输无法原子回滚，不承诺跨回合 exactly-once。
   - `internalStatusLeak` 片段级脱敏（内部路径/堆栈/日志标签/协议 JSON/**凭据形状 sk-/AKIA/JWT/赋值形态**；占比>30% 或剩余<6字 heavy 整条回退）——挂在 `sanitizeFinalReplyText` 统一出口（群聊/私聊/转图路径全覆盖）+ 仿真 `simSendMessage` 发送前同源调用。
   - 工具参数形状 JSON（`looksLikeToolArguments`）主链路按行丢弃、仿真整批拒绝——同源唯一实现于 replySanitizer。
   - 违禁词出站拦截 + censor 双级词表（outboundThrottle，适配器层兜底）。
   - 仿真普通聊天由模型调用 `simSendMessage`，持久化相关最终说明经 `simFinishTurn` 转用同一发送路径。正常行动阶段被点名或正式托付回合零发送且模型输出普通最终正文时，运行时提醒一次；随后仍输出正文可能经同一 `executeTool → simSendMessage` 兜底发送。沉默声明、含沉默元话术/整条括号状态标注及本轮显式 `simDecide` 不进入兜底；`silent/deferred` 还阻止本轮发送动作。拒绝的自然说明须显式调用发送工具，内部理由不自动外发。
4. **控制台**：scrypt 账密 + cookie 会话/长令牌；配置写走 configRepository（revision 乐观锁 + 原子写 + 自动备份）；API key 脱敏读写。角色操作沿用认证入口并验证操作/记录标识，可暂停/恢复自主行动、暂停/恢复/取消目标、删除角色记忆。删除来源会清理依赖记忆并撤销依赖目标；此传播针对新角色结构化状态，不声称清空所有历史归档、模型上下文或第三方留存。
   - 同一认证入口新增作品归档/恢复/删除、订阅暂停/恢复/移除、反思重置检查时间、共享偏好审核/撤销；操作名、id 和 payload 严格校验。作品恢复使用当前版本乐观锁。反思重置不清空每日次数，也不绕过新依据与预算限制。
   - 结构化收尾 `simFinishTurn` 由模型显式选择聊天、兴趣、拒绝、排期、等待、完成或放弃，不解析中文内容补状态。至多两条记忆与一次目标变更先在草稿验证，再以角色 revision 比较一次提交；来源、完成回执、未知字段与嵌套字段沿用实际业务校验。`throughSeq` 与引用消息在提交前核验，不能标读未展示消息。保存失败不发送提交说明，也不标读。
   - 保存成功后封住本轮；可选说明经过原 `simSendMessage` 清理、群绑定与限额。发送先保存独立 pending 回执，使用仅限此次同步公告的精确角色/目标版本许可，不能使 completed 目标恢复一般行动权限；逐条重查暂停、切人设、来源撤销、活动版本和预算。发送失败保留真实角色状态与未读，不自动重发；最终回执 CAS 冲突保留 pending 待恢复核实。同批收尾后的调用各记未执行结果。聊天工具须显式声明 `continuation=chat/interest_only`，语义真实性仍由模型负责，字段不能保证它不会说错。
   - 尝试过结构化收尾（含失败）后及最后两次工具轮仅暴露收尾工具并请求 `tool_choice: required`，本地拒绝其他工具；provider 忽略要求或未启用工具时保守结束，不扩充轮数或兜底发送。自主回合各阶段普通最终文本仍只留内部；被点名/正式托付在正常行动阶段保留既有普通文本兜底。固定协议位于人格与按需工具说明之前，动态阶段/来源置于请求末尾；记忆、网页、工具正文与人格示例不能覆盖规则。未添加客户端缓存哨兵、跨渠道缓存或新出机目的地。
   - 撤销使用独立于会话快照的 Redis 活动版本，机器人与独立控制台共享；旧 session 保存或重置不能覆盖该版本。发送、行动和后台活动复核最新版本，后续回合清理绑定旧版本的模型历史。已进入外部发送或任务执行的动作仍无法保证撤回。
   - 旧会话尚未通过实际入站绑定 bot 时，群详情返回待绑定状态和空角色活动，角色/活动管理拒绝操作；生活页不把默认机器人身份套到未绑定群。独立控制台不创建空 bot 分区或伪造入站事件。
   - 跨群偏好只共享同 bot/人设的角色观点/兴趣，模型只能提议，来源群控制台管理员逐条批准；投影不输出来源群或群友标识。正文来自原观点全文，不能自动保证无隐私，批准前必须审核正文；源记忆删除/修正或上游共享撤销会递归失效派生投影。各群运行/查看时清理派生记忆、目标、作品版本，发送前复核指纹阻止旧上下文外发。
5. **秘密与落盘**：`config/message.yaml` 明文 key（R2）；`console-users.json` scrypt；原仿真会话/记忆/好感度/初始提示词存 Redis（`shiloh:sim:*`）；新角色状态存 `shiloh:character:v1:<botId>:<personaId>:<groupId>`。身份以稳定 `personaId` 而非人设文字哈希分区；新自我笔记、情绪、作息、生活线使用同分区附属键，旧全局键保留且不自动迁移。作息单独保留管理员默认：没有分区作息时，只有 `setBy=admin` 的旧全局值可继承，旧 agent 值不继承；控制台设置会同步当前已知角色并保存此默认。生活线概览汇总当前各群角色的分区记录，不迁入旧全局生活线。令牌账本 `data/token_usage/*.ndjson` 只有计数与金额；情节记忆/归档 NDJSON 在插件 data 目录。
   - 角色状态的读取失败、坏 JSON、范围不符均抛错，不用空状态覆盖；生产 Redis 使用租约 token 校验的 Lua 原子提交/释放锁，失去锁的修改不提交。无 Lua 的内存适配器只用于同进程测试。此锁保护角色数据写入，不构成多进程执行器选主。
   - 行动先持久化 `pending`，再调用工具并保存 `succeeded/failed/unknown`；重启恢复将遗留 `pending` 标未知。未知副作用暂停目标等待核实，避免自动重复；已取消目标不被迟到回执重新激活。成功回执只证明运行时拿到相应工具结果或投递确认，不证明搜索内容、观点或世界事实真实。
   - 状态有界保留：保留最近 64 条一般回执和最近 16 个终态目标，保护仍被记忆/目标引用的证据来源；待确认回执也不会作为普通旧记录清掉。另有总容量限制，满载时拒绝新增；这不是永久审计归档。
   - 本批附属存储：作品 `${characterKey}:workspace`、反思 `${characterKey}:reflection`；订阅 `shiloh:character-subscriptions:v1:<botId>:<personaId>:<groupId>`，共享偏好 `shiloh:shared-self:v1:<botId>:<personaId>`（分量均编码）。作品最多 24 件/12 版/12000 字，保护其引用的回执；删除记忆会清理对应作品版本。作品区仅存文本，不提供任意文件路径或二进制资源托管。
6. **调度与预算**：仿真默认唤醒限频（2/min、12/h）+ 每群每日 40 回合 + **每日金额预算（默认 ¥5，读令牌账本）**，实际按群配置生效；超限按原预算规则停止或延后，`TURN_BUSY_LEASE` 与进程内运行集合防重复回合。自主目标复用群调度、参与边界和预算，不享受正式承诺的预算豁免；最多 3 个活跃目标，检查间隔至少 15 分钟，有期限和尝试上限。
   - 到期自主目标的唤醒优先级为 31，高于自动回复检查 30，低于开场 40、真实消息与正式托付，避免回复检查抢走目标聚焦；不改变仅@参与限制或自主执行身份。
   - 当前假设单个仿真执行进程。群会话绑定一个 bot，第二个 bot 的同群入站忽略；不同群可绑定不同 bot。角色分区和写锁不能据此宣传为同群多 bot 并行或多执行进程容错。
   - 仿真仍按单个执行进程部署。原 QQ 群会话仅由已有账号读取。显式绑定的新会话按平台、命名空间、账号、类型及会话 ID 隔离未读、调度、限频和实际花费。撤回仅影响事件所属账号的会话，恢复只执行当前宿主管辖的地址。其他平台需要显式绑定和统一发送端口，QQ 专用工具及 QQ 原生消息段仅在 QQ 会话使用。
   - 独立宿主按当前已验证账号分别领取到期承诺及续约问询，按任务持久化地址分派。同一账号串行，各账号共用原子账本写入及执行租约，等待外部回执的账号不会占住其他账号的派发。
   - 独立群摘要与情节按角色和完整平台会话地址保存 Redis 有界来源、聚合及确认回复 ID，目录与详情原子比较版本提交。普通文字群未点名消息也可参与摘要，私聊不生成群摘要；私聊情节必须匹配当前已核验对话者。摘要只经显式 `midtermSummary` 后端生成，无主模型回退；`midtermMemory.enabled: false` 停止该出机链路和摘要读取。专用模型最多收到有效旧摘要和 200 条原消息的时间、作者、显示名及每条 160 字正文，无主提示词、工具或附件；全输入和输出检查宿主已知秘密，固定服务拒绝重定向，30 秒完整 deadline、512 KiB 响应和最多 8000 输出 token，HTTP 不重试，队列最多尝试 3 次。失效水位让撤回、遗忘和停用涉及的旧聚合整体不可读，即使原消息已退出有界缓冲；绑定、隐私或停止撤销在途结果。摘要与情节只进入用户资料上下文，旧人设的情节显式归因。情节时间在三种 Core 会话路径统一显示显式 `Asia/Shanghai` 日期时间，原始时间戳及权限不变，不受服务器时区影响。情节仅从已确认投递补记，失败不重发，平台投递与本地补记不保证原子；关闭 `episodicMemory.enabled` 停止补记和读取。旧插件无完整来源归属的摘要及全局情节文件保留，不自动导入。
   - 好友私聊迁移限同一账号、角色与会话中该好友本人的自述事实，按原来源范围接续索引、详情及隐私约束。文字回合按当前发言者查询，群内允许本群来源和原本可跨群的档案，好友私聊限定本会话的本人自述。每次最多投影四条带证据类型的文字摘要，原始引用、内部标识及直接召回段落不进入会话历史。文字回合调用模型、执行工具及尝试回复前复核人物记忆失效水位，历史携带同一水位。好友撤回会持久撤销匹配的事实来源，即使迁入的原消息未进入独立宿主收件队列。
   - 本人清空、禁用及启用记忆命令独立于模型执行。入站核验当前账号、角色版本、发言者及会话，好友私聊另核验对话者。命令只接受独立文字，首次入队还检查平台发送时间。群内只影响本人在本群的记忆，私聊操作只影响同账号和角色下本人的各场景。队列按账号处理，隐私状态和命令回执原子提交，撤回或换绑会阻止未提交操作。同账号的新模型回合等待命令处理，入队时取消相关角色已有的模型请求与待投递许可。已发出请求按外部服务实际收到的数据处理，迟到结果不能继续执行。固定确认只到原会话，发送前领取确认回执，重启时跳过重发。
   - 空闲后台与正常回合互斥；仅@、睡眠、暂停或预算不足时不启动后台自主活动。反思至少 6 小时、每日最多 2 次，要求 2 项未处理依据，调用前持久化预留并计群回合，记录实际 token；失败仍冷却，重启不自动重复。独立路径不带工具和发送端口，30 秒超时/取消；只写推测性观点/兴趣及等待/放弃已有目标，不改身份、权限、关系分或宣告目标成功。
7. **网络出机**（safe fetch 类）：`fetchImageBase64` 限 http(s)/2MB/15s；webParser/searchInformation 沿用各自实现的 SSRF 防护；梗提取**只喂群内消息给 LLM、不联网**。
8. **角色影子回放**（`scripts/characterReplay.mjs`）：直接装配编译后的仿真引擎，不导入宿主 adapter；每个样本新建内存存储、捕获发送，搜索、订阅更新和工作器任务固定走合成端口，不访问真实 QQ、生产 Redis、RSS 或外部工作器。正常模式调用配置中的主回合、独立反思和明确启用的隔离一致性实验模型渠道，分别保留 stage、usage 和耗时；实验审核复用 memory 任务路由，元数据明确区别于生产默认关闭的独立审核路由。`--dry-run` 不读私有配置且不联网。逻辑模型调用默认最多 60 次、实际 HTTP 最多 80 次（包括兼容重试与有效降级）、整次默认 10 分钟，另有单请求和事件超时；达到限额后保留已发生结果并跳过后续事件。异步请求绑定事件和阶段，取消后未收敛则记录缺失并停止后续事件，不把迟到响应归给下个事件。证据不导出请求正文、完整人设、Authorization 或 provider 附加隐藏推理字段，按既有 scrubber 精确清理配置中的秘密/长提示文本；这不保证任意上游响应片段都不含敏感内容，分享报告前仍须核对。旧报告拒绝覆盖。`characterAcceptance.mjs` 只读取已保存证据，重算本事件前后差量并核对连续性、manifest/summary/条件；审核调用不能充当业务工具成功证据，人工表绑定候选文件 SHA256。哈希只证明本地证据一致性，不能认证报告来源。离线、缺对照、缺人工评审、真实群未观察或部署未验证时，不判阶段 7 完成。
9. **公开订阅**：最多 8 个，RSS/Atom/GitHub releases，仅 HTTPS 公网且无 URL 凭据/凭据参数。解析全部 DNS 地址并绑定已核验 IP，逐跳重验重定向（最多 3 次）；请求 10 秒、正文 512KB 上限，XML 禁用外部实体。至少 1 小时、最长 7 天；预占检查时间、失败退避、seen 128/缓存 16 条，暂停/删除后迟到结果不得提交。资料标为不可信且不授予权限，不自动代表事实。
10. **可选工作器**：管理员固定配置 HTTPS 或 loopback HTTP 网关，未启用不暴露工具；模型只能指定研究/图像/浏览任务与可见来源，不能选 endpoint、凭据、群号或文件路径。自定义桥协议 `POST /tasks` 含固定 scope、task 和 schemaVersion，`Idempotency-Key` 等于先写入的行动回执 ID；认证 token 不进入模型。30 秒超时，运行期间重复授权检查；撤销/超时以独立 2 秒 `DELETE /tasks/:taskId` 最佳努力取消，拒绝重定向、响应上限 128KB。协议不合法、异常、超时或可能已执行的 HTTP 错误记 unknown，相关目标暂停，不能盲目重试。成功文本作品完整存入本群草稿，公开仍走发送边界。外部机器实际隔离、权限与幂等由网关实现，本插件不因此提供浏览器沙箱或原生 OpenClaw API 兼容。
11. **实验性角色一致性审核**：`simulation.consistency.enabled` 默认 false；启用还须完整配置 `taskAiConfig.characterConsistency` 的 apiUrl/model/apiKey，配置缺失明确失败，不回退到 chat/memory。只读候选正文、草稿角色状态和有界可见来源，严格解析 accept/revise，不执行工具或自动补状态。记忆/收尾/反思在私有草稿校验后审核，CAS 保存前再核对权限与来源；中途文本和工具回复走同一审核入口。每回合总共最多 3 次，非收尾至多占 2 次，反思最多 1 次；每次 15 秒、900 输出 token，实际 usage 计预算。错误/超时/拒绝只阻止本次提交或发送并要求模型收尾，不能提升权限或恢复撤销来源。模型审核可能误拒或漏检，不是确定性语义保证；默认关闭时原结构、CAS、权限、去重和未知投递保护仍有效。
   - 承诺沿用原 Redis 详情与索引，token 锁内用 Lua 原子提交两者；领取保留索引，独立 run ID/租约区分待执行与已开始。未开始的遗留领取可恢复，执行中断后记 unknown，不自动重放；取消保留终态，旧 run 不得结算或重新排期。同群托付独立排队，不合并成聊天唤醒，以实际发送/动作回执结算。终态详情保留 24 小时、失败日志最多 20 条，不提供永久审计或跨系统 exactly-once。旧版本失去索引且无法证明结果的任务进入未知日志，需核实后重新托付。
   - 新定时承诺记录创建时的绑定归属，显式绑定记录按角色和完整会话地址分区。领取时仅处理宿主负责的平台。续约、唤醒和静态发送复核原归属及本次执行捕获的绑定版本，宿主限流后再核验一次。旧兼容承诺在会话切入显式角色后停止执行。
   - 迁入的一次性 QQ 提醒通过现有静态发送端口，群内点名原创建人，私聊直接发回原好友。使用目标的正文过滤和绑定检查，省略旧消息引用及额外动作，不发送续约或失约公告。未确认投递结果按原承诺调度的未知状态停止重发。
   - 委托记忆 bot/console 共用 Redis CAS，校验、修改和提交针对同一最新文档，损坏文档或无 Lua 能力时拒绝写。
   - 显式绑定群的委托记忆和仿真群笔记按角色及完整会话地址读写，原兼容群键保留。控制台删除委托记忆时校验所选分区和会话。仿真切换绑定时废止旧唤醒、重试及模型上下文，群历史仍受原来源权限和账号归属约束。
   - 普通 QQ 聊天自动抽取的事实、别名、待抽取批次按角色与完整会话地址存储。抽取与反思在模型调用及受控写入前复核绑定，重启恢复按批次的原版本检查。QQ 记忆查询和清理按当前角色分区，二次确认绑定原版本，来源撤回和群级隐私限制继续生效。独立 Core 的显式群知识、工作流和教学称呼按完整会话地址维护；旧插件裸群号数据仍按原群维护且未自动导入。
   - 语义记忆关闭/重装会拆归档钩子、清排队定时器并 abort 旧索引/召回/embedding/rerank，迟到响应不再索引或强化；已交给 OS/上游的 I/O 仍不能回溯撤回。启动与增量按群过滤和 retentionDays 读取仍存在的归档，最多 16 条分批向量化，成功落盘后提交实际正文覆盖的消息 ID 检查点，失败保留待办。每条保留原有 400 code point 上限，窗口按完整行分块；归档已被清理的原文不能恢复。
   - 记忆纠错仅关联同 bot/group/turn 已确认发送的实际回复 ID；明确引用不回退本群最新回复，无引用只关联最新确认回复的对象。缓存有界且重启失效，缺来源时保守跳过；来源登记只证明这些 chunk 注入过该回合，不证明模型逐条采用。控制台畸形 Cookie 独立容错，整个请求解析、鉴权、路由处于异步异常边界内，错误仅影响本次请求。

### 独立语义来源与检索

- `semanticMemory.enabled` 默认关闭；启用必须显式声明完整 embedding 端点、模型和环境变量凭据，可选 rerank 也独立声明。无插件配置、主模型或隐式端点/凭据回退；关闭及 `--check` 不访问服务。
- 可信 Core 入站提供账号、Agent、完整会话地址、原作者、消息 ID 和时间。专用 Redis 来源库按宿主实例及完整作用域隔离，目录与正文 CAS 同步；最多 200 个分区、每分区 2000 条、每条 1600 UTF-16 单元、最多 90 天。不读取旧插件归档、滚动摘要或无真实接收角色的旧索引；引用/转发/附件正文及机器人消息不能冒充本人来源。群聊只同会话召回；私聊实际对话者可检索同账号、同 Agent 当前可访问群中的本人原文，其他作者在向量/关键词/重排之前即排除，不读其他好友私聊。
- 私聊跨群读取的主体与查询来源由适配器的真实作者、消息 ID 和时间确定，正文和模型不能选择他人。缺少可信查询来源时保留原同会话行为，显式不匹配则保守拒绝。来源群须仍绑定当前 Agent，并通过当前账号的机器人自身成员证据；QQ 使用 `get_group_member_info` 的 `no_cache: true`，完整地址、机器人 ID 与新鲜时间均复核。自定义适配器不支持成员读取时不授予跨群权限。平台访问在提供方请求前后、模型与投递前重新读取，来源群换绑/撤回或停机取消在途读取；来源删除、损坏和持久隐私规则也约束返回投影。重复消息 ID 使用完整来源哈希区分。
- 模型执行器在每一次实际 HTTP 派发前等待宿主的异步 `ensureCurrent`，包含生成参数兼容重试、工具规划器与文字渠道的降级；同步 `isCurrent` 同时约束最终派发。任一次异步授权拒绝即锁定该调用失效，不能因后续授权恢复而尝试其他渠道。取消可以结束挂起的授权等待，迟到放行不能继续派发。Core、独立 QQ 宿主和旧插件仿真装配均传递此复核，主回合、一致性审核、社交许可审核与后台反思分别重查其有效来源和活动范围。自定义 Core 模型宿主须在每次实际提供方请求前等待 `YTapi`、`reviewCharacter`、`reflectCharacter` 及 `judgeSocialPermission` 的第五个参数 `ensureCurrent`，不能只在第一次调用时检查。
- embedding 仅接收已核验原文或获准查询，不接收账号/作者标识；rerank 仅接收查询及有效候选原文。任一整条原文失去权限就剔除该条。混合查询缺少逐句归属且本场景存在停用时，只做本地 BM25，不发查询或重排请求；已核验私聊查询按真实对话者的本条来源检查，其他群友的停用不改变本人权限。来源授权在实际请求前及返回后重查，换绑、隐私准入、撤回和停止贯穿取消。来源删除/损坏以及持久隐私墓碑约束迟到写入、投影和使用；后台会清理失效、过期和超额原文，不承诺物理擦除备份或第三方留存。
- 索引每批 8 条、最多 2 个分区并行；来源先持久化，失败至少退避 60 秒，重启接续。目录只扫元数据，非脏分区至少 60 秒巡检。向量空间摘要改变后重新索引，旧空间向量不参加新查询。向量限制 2–4096 维、有限非零数值；来源不可被同消息 ID 重归因，状态损坏保守拒绝。
- 固定精确 HTTP(S) 端点，禁止重定向，不做 HTTP 自动重试；响应上限 1 MiB，鉴权只送配置端点，输入拒绝已知宿主秘密，提供方错误正文不写日志。Core 有界查询与索引信号贯穿 fetch 和响应体；已提交上游的数据不能保证撤回。召回资料不作为指令，投影和派生普通回复不另存为失去来源关联的历史、情节或自动群学习；显式工具保存仍受各自依赖规则约束。

### 独立显式历史查询

- `history.enabled` 默认关闭，启用后从真实入站开始保存有界顶层文字来源，按完整平台、命名空间、接收账号、Agent 与会话隔离。默认保留30天、每会话1000条；允许1–90天、50–2000条、每条4000字符，目录最多200个会话。该来源库不依赖 embedding、摘要或画像开关；不把引用、转发、合成事件、旧无来源缓存当成本人原话，不自动导入旧归档。
- `chatHistoryTool` 由当前真人请求的模型选择。群内只能检索当前群最近60条有效来源及可见长期记忆；群内禁止跨群归档。好友私聊只查经过宿主核验的本人和同账号、同Agent当前授权群中的本人原话，不读其他好友会话或其他作者。跨群先核验双侧当前绑定及机器人新鲜群成员资格，再读对应来源正文；模型不能传入来源群列表或扩大身份范围。
- 按北京时间日期整日或带时区时钟查询，每类来源默认20条、最多50条，使用各来源游标与真实记忆ID展开详情。始终标注有界覆盖和 `complete_history:false`；未命中或不可用不能解释为从未发生。索引和详情沿用同一人物隐私规则，群内跨群可移植事实隐藏原群、消息ID和原文摘句。
- 原文读取后及每次模型HTTP、兼容重试、发送和最终使用前重新核验持久隐私、撤回、来源正文与绑定。历史结果及本轮派生回复只作临时投影，不写入文字/仿真模型历史、情节、自动群学习、持久工具观察或角色记忆/目标/作品；本轮后续只允许继续查证、回复和有限安全收尾。停止、换绑和来源撤销取消在途使用，工具结束撤销工具能力；新回合重新读取和授权。开启后的本地有界原文仍按保留期管理，已提交模型或已经发出的消息不能保证撤回。

### 独立群教学与资料管理

- 群内自动说法属于 Agent 与完整会话；显式教学只在相同平台、命名空间、账号、会话类型及 ID 内共用。独立 `groupMemoryExtraction` 且 `groupMemory.enabled: true` 才启动提取，无主模型回退。自动说法只由确认普通回复触发，教学由语义模型独立判断，不能把单人群内说法描述成多人共识。
- 启用群记忆但未配置提取后端时，只读取和管理已有资料，不捕获或启动新学习。旧教学导入共用原生消息来源格式，拒绝机器人输出、引用和损坏消息段；同 ID 的无效副本不能被忽略。损坏撤回通知中止提交，工作流限 20 人。旧文件缺附件名，或其文件 ID 无法对应原生稳定引用时留源，不以旧 `fid` 或正文补造证据。
- 原消息 ID、作者、时间、逐字摘句与不可变来源一起保存，知识与任务确认使用单文档 CAS。成员及角色由适配器核验，QQ 单成员查询禁用缓存；工作流只允许当前管理员教学，提交前刷新并限制角色证据 1.5 秒有效期。角色平台与 Redis 不提供跨服务原子授权。目录或身份未知时拒绝教学，模型不能自行声明管理员、成员 ID 或文件路径。
- 共享教学还检查来源 Agent 的人物隐私及关联者规则。相同账号的隐私命令取消所有可能使用共享资料的在途记忆回合；模型和发送前重查资料。直接群资料及使用它的生成回复不再写入文字/仿真模型历史或情节副本。撤回、停用、遗忘、换绑、关闭和停止约束迟到写入，无法保证撤回已发送内容或已经提交服务的数据。
- `groupKnowledgeTool` 仅在群文字按会话显式授权后可用，不进入好友私聊或仿真非真人/自主工具面。仿真真人唤醒复用同一管理工具和权限边界，不能由自主回合或保存的工作流单独触发。删除按创建者或当前管理身份判断；精确名称遗忘拒绝歧义，同来源共享教学一组撤销，自动事实仅当前 Agent 受影响。清空须当前管理员在 30 秒内以另一条真实消息确认，同真人/账号/会话/绑定；空集合也保存截止时间，拒绝清空前延迟捕获恢复。墓碑超容量拒绝写入，不静默淘汰墓碑。
- 通知只由当前真人请求的主模型工具选择发起，保存的工作流本身不授予行动权限。请求摘句与通知正文须逐字来自当前原话，发送前再核验成员、工作流、绑定和隐私；一次动作先登记尝试，未知回执不自动重发。仿真真人唤醒的通知同样经过统一发送回执。原插件裸群号教学及工作流不自动复制；显式离线导入也须逐条回源，缺少完整账号/原文/作者权限的条目留源。

### 人物记忆与跨场景召回

- 新人物存储为 `shiloh:person-memory:v1:<botId>:<personaId>:person:<userId>`，独立索引、详情和来源失效策略。账号由实际事件提供，私聊工具不接受模型改写查询主体；群聊工具仍只读当前群。未知旧画像/私聊数据不迁为跨群来源。
- 群间可携带信息须为本人在群中自述的称呼、兴趣或普通偏好，明确 portable、非敏感且没有其他关联人物。事件、关系、推测及私聊来源都留在原场景；confidence 和 affinity 不授予披露权限。
- 私聊原始历史先按已授权群、接收机器人/人格、真实作者、消息类型和撤回状态过滤，再进行关键词/embedding/rerank；第三人转发与引用正文不进入本人向量候选。旧归档缺少 bot/persona 时，只在宿主确认当前账号所在群及人格绑定后回源；找不到真实作者的旧混合窗口不补猜身份。
- 独立私聊按接收账号核验会话对话者。会话 ID 与对话者 ID 不同时，历史只复用同会话、同对话者的记录，私聊人物事实只在原会话向本人提供。撤回按账号、会话和消息 ID 持久化。接续的 QQ 私聊提醒按原创建人核验接收者。
- 记忆和摘要进入资料消息；系统层仅持有固定使用规则。模型摘句必须逐字命中真实源消息，来源字段不能由模型自报。一般仿真印象不自动进入跨群人物档案。
- 独立人物事实学习须显式配置 `personMemoryExtraction`，只接受 `baseUrl`、`name` 和 `apiKeyEnv`；未配置不装配提取器，不回落其他模型。声明后启动和 `--check` 要求凭据，迁移预览仅检查格式。群仿真沿用 `simulation.personProfile.enabled` 停用开关，默认 6 小时冷却，从 20–40 条有真实消息 ID 的完整文本提取本人原话，排除引用正文、合并转发和截断文本。调用受人物隐私排队、撤回、绑定和取消检查约束，迟到写入在存储提交前复核。群知识、工作流及角色反思已有独立装配，时间视图已有平台无关实现；这些路径的真实模型验收与旧知识/工作流/摘要/情节资料的可验证迁移分别跟踪，RAG 尚未接入独立宿主。
- 私聊和群文字学习须另设顶层 `memorySystem.enabled: true`，默认关闭。只从确认送达的普通文字回复收集用户来源，沿用 90 秒静默或 6 条批量节奏；设置只接受开关、0–3600 秒防抖和 1–40 条批量上限。收件确认与学习入队可恢复但不会盲目重发；来源与模型结果有界保存，CAS 原子更新最多 200 个缓冲，每个最多 60 条、每条 4000 字，结果先保存再写事实，同一结果可幂等重放。失败最多 3 次自动尝试，保留耗尽记录。引用、转发、工具结果和低信号资料不学习。私聊的会话 ID、真实对话者和原始时间不能由模型或房间 ID 代填，私聊事实强制本会话本人可见。换绑、换人、撤回、隐私变更、关闭功能或停止时拒绝迟到结果，每次写入传递最终提交保护。
- 人物提取请求固定使用配置的后端与凭据，不跟随重定向，不在单次 HTTP 调用内重试；文字队列最多 3 次失败尝试另行调度。40 秒覆盖异步授权、网络及读取，响应最多 512 KiB、输出最多 2000 token。显示名和正文分别截到 20/400 字之前检查完整输入中的已知宿主凭据，完整结果同样检查凭据。只接受不超过 64000 字符的严格 JSON 数组，拒绝模型工具调用；安全错误不回显提供方正文。群仿真后台任务持有本会话状态直到有序交还，保留提取期间的新入站消息和待唤醒，取消不推进提取游标。
- 删除、停用、撤回使用持久墓碑；重复撤回幂等。检索、工具输出、原始上下文和异步写入重查有效性，重新索引/重启不复活。删除涉及其他人的关系记录时，原作者的同源摘句也受限。无逐条来源旧聚合失效，后续摘要仅从允许的新来源重建。
- 原始归档仍按归档保留策略管理；此机制保证后续使用受限，不保证已发送内容、已经提交第三方模型的请求及第三方留存被撤回。归类仍有模型误判风险；来源核验能证明摘句来自原文，不能证明语义判断绝对准确。仿真角色自我跨群共享仍遵守上文管理员审核规则，与人物通用画像不是同一授权通道。

## 四、已知残余风险

- **R1** 出站拦截是启发式（正则形状），精心构造的绕过可能漏拦；heavy 兜底保证"宁可少说不可泄密"。
- **R2** `config/*.yaml` 中 API key 明文存放（同机读权限者可见）。
- **R3** `custom_tools/` 与 MCP server 是任意代码执行面，信任边界=部署者本人。
- **R4** 上游 provider 对发过去的内容的留存与使用不受本插件控制。
- **R5** 仿真放通的既有工具（toolPolicy open 默认面 / extraTools 追加）继承其自身实现的安全性（如搜索的关键词出网）；敏感工具（禁言/撤回/送礼/抢红包/QQ空间/改名片/@全体管理/reminder）RESTRICTED 默认禁，解禁须显式 `toolPolicy.allowTools`。
- **R6** 同一外部动作与 Redis 回执写入不能组成跨系统事务。超时、中断或回执丢失可能产生未知结果；暂停目标和未知标记降低重复执行风险，不能证明外部动作未发生，也不提供自动撤销。
- **R7** 实验语义审核仍有漏检，且推理/传输超时或输出截断会保守阻止正常消息；目前默认关闭，固定用例通过也不能替代多轮实模与人工验收。

## 五、发布前检查清单

1. `npm run verify:phase` 全绿（typecheck + boundaries + 全量测试 + 控制台前后端检查）。
2. 改过出站/工具边界 → 构建后运行 `node --test tests/replySanitizer.test.js tests/simSilentDeclaration.test.js tests/characterRuntime.test.js`；再以 `tsconfig.backend-tests.json` 编译领域测试并运行对应的 `simulationDomain` / `characterState` 用例。
3. 新增数据出机目的地 → 同步「数据出机清单」表。
4. 改过仿真安全相关 → 冒烟（假 Redis/假模型）确认零外发路径无回归。
