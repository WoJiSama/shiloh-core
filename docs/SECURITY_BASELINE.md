# 安全基线与威胁模型（SECURITY BASELINE）

> 维护规则：**改动了任何一条边界所描述的代码，必须在同一个提交里更新本文对应条目。**
> 发布前检查清单见文末。最后全面复核：2026-10-26。本轮局部边界更新：2026-11-19，覆盖普通文字工具、持久清理/恢复、三角洲、游戏配置与接续和 Linux 骰子 runner；最终构建与生产交付另看发布回执。
> 自主角色相关边界更新：2026-11-11，依据本地实现核对；已发布版本证据见自主角色路线文档第 12.14 节，本次系统修复的本地交付见第 12.15 节。

## 一、威胁模型

| 主体 | 能力假设 | 主要防线 |
| --- | --- | --- |
| **QQ 群友**（含陌生群成员） | 可发任意文本/图片/表情/戳一戳；可诱导模型（prompt injection）；可刷屏 | 群白名单、工具面裁剪、发送白名单（仿真工具目标绑定会话群）、出站脱敏与审查、频率限制 |
| **被注入的模型**（上游返回被诱导的输出） | 可尝试输出内部路径/凭据/工具参数 JSON；可尝试在仿真回合越权发送或借群友身份执行 | internalStatusLeak 出站脱敏（含凭据形状）、工具参数 JSON 拦截、发送配额与冷却、执行主体校验；文本兜底同样经过工具执行与发送边界 |
| **控制台用户** | 拿到控制台访问权后可改配置、看统计、管理仿真 | scrypt 账密 + 长令牌、revision 乐观锁、建议绑定 127.0.0.1/内网、凭据脱敏读写 |
| **同机其他进程/用户** | 可读插件目录与 Redis | Redis 由 TRSS 宿主管理；config 明文 key 的残余风险见 R2 |
| **MCP server / custom_tools**（第三方扩展） | 任意代码执行能力（stdio 子进程/热加载 JS） | 仅 master 手工部署；不随包分发；工具结果截断 8000 字符 |
| **上游 provider**（LLM/搜索/embedding/VLM） | 收到发过去的全部内容 | 见「数据出机清单」，逐项可关 |

明确**不防**：腾讯侧风控（靠出站节流降低概率）、宿主机被完全攻破、上游 provider 滥用数据。

## 二、已实现边界（按攻击面）

1. **准入**：群白名单 `enableGroupWhitelist/allowedGroups`（默认开）；用户黑名单；私聊白名单（空=仅主人）；`#` 命令与仿真流互斥；违禁词命中即中断该群进行中回合（入站+出站双向）。
   - QQ 会话绑定由宿主事件的账号和会话以及本地 `agent-bindings.yaml` 解析，账号矛盾时拒绝聊天回合。绑定只选择角色和人设，准入及工具权限仍由既有策略控制。显式角色使用保留的角色状态前缀，两个 QQ 入口均拒绝与旧人设 ID 冲突的绑定。
   - QQ 普通聊天回合固定绑定，发送和开始执行工具前复核，群聊回合持久化记录带原绑定标识，恢复仅使用原账号。仿真回合在主模型调用、工具和逐条消息投递前复核绑定。检查覆盖宿主控制的动作入口，已交给工具或平台的动作依据实际回执结算。
   - 带绑定的原生 QQ 工具使用入站指定账号。改名片、禁言、戳一戳、撤回等操作逐项复核原绑定；异步读取成员、消息或凭据结束后，在后续动作前再次复核。QQ 空间工具读取凭据后，HTTP 派发继续受原绑定约束。
   - 显式 QQ 绑定的智能续话、严格会话追踪、上一轮摘要、近期话题及互动提示按会话地址和绑定版本隔离。入站及出站的违禁词中断沿用该范围，并在出站延迟或限流结束后复核。无显式绑定时使用原状态键。
   - QQ 普通聊天、独立文字回合和群仿真的模型请求在实际 HTTP 派发前核对原绑定，同一渠道的兼容性重试、备用模型以及工具续轮遵守该检查。迟到模型结果不用于新请求、工具执行或回复。Strict 批量判断剔除已失效的条目，单条回退复核该会话。上游服务已收到的请求由其处理。
   - TimingGate、仿真唤醒预判、群梗提取和人物画像抽取的侧路模型也在 HTTP 派发前复核绑定与有效来源。群梗与人物事实在模型返回和落盘前复核撤回、隐私与活动版本，已撤销的结果不能写入或推进游标。唤醒预判、群梗和人物事实提取在智谱官方 `glm-4.5-flash` 或 `glm-5.3-flash` 请求中设置 `thinking.type: disabled`。人物事实提取告警记录固定失败类型及 HTTP 状态。
   - 旧版 Yunzai 与 OneBot 撤回通知均按账号、会话和完整消息 ID 处理人物记忆。原通知账号冲突时不入队，缺失时仅使用宿主能确定的唯一 QQ 账号。归档关闭和当前角色不可解析时仍可撤回该账号已记录的来源。
   - 近期私聊缓存按接收账号和对方 QQ 隔离，机器人回复记录在对方 QQ 的分区。历史兼容只读取带匹配账号来源的旧入站消息。聊天回合、任务状态查询和近期记录命令均使用事件账号。
   - 显式绑定的普通工具状态及其投递证据按会话、请求者和绑定版本隔离。图片任务保存接收账号及原绑定版本，恢复时须匹配原版本，已尝试投递的任务跳过补跑。原 QQ 提醒按登记归属查询、取消和触发，附带工具及直发在当前绑定校验后执行，提醒正文经过最终文本清理。
   - 普通聊天和仿真从 QQ 适配器读取统一的正文、点名、引用和附件。会话账号及目标来自宿主事件，引用只提供被引用消息的上下文。
2. **工具面**：
   - 主链路：`oneapi_tools` 全局白名单 + 按消息意图过滤 + 路由锁（toolScopeLocked）；私聊默认零工具（仅表情可开）。
   - 仿真回合：装配期只挂本轮仿真/角色工具和 `toolPolicy` 解析出的额外工具。默认 `open` 采用内置普通工具面、全局/按群 deny 做减法；RESTRICTED 敏感工具须显式 allow，自定义工具须显式 extra 放通。未装配的工具不可调用，已装配仍须通过执行主体检查。
   - 独立 Core 的宿主工具注册表使用平台无关上下文：固定当前绑定及执行主体，提供取消信号和当前权限复核，不传原生 QQ 事件。内置注册项和自定义注册项分别遵循既有 `open`/`legacy`、全局与 QQ 按群禁用、显式追加规则；注册表接入群仿真；普通文字群和好友私聊只接入 `textGroups[].tools` / `privateChat.allowTools` 显式授权的通用子集，并与实际注册表和原工具策略取交集。deny 优先，自定义 MCP 别名仍须原策略显式放通；未配置提供器或没有对应平台端口时列名也不授予能力。自定义注册项不能借用内置名称取得自主权限或未知结果豁免。执行前和异步结果返回后复核绑定、持久化活动版本及来源权限；实现须在每个外部请求前等待异步 `ensureCurrent()`，内置网页逐跳执行。其他进程的撤销在下一次授权边界发现，不承诺撤回已经外发的请求。当前会话撤回即取消在途注册工具；完成或失败也立即撤销本次上下文。取消及失效正文不进入回执或模型，已经获得的有效用量仍计账。
   - 独立宿主搜索和网页工具默认都不提供。`tools.search` 须完整声明服务地址、模型及密钥环境变量，不回落主模型；模型不能选择 endpoint 或凭据，搜索服务请求拒绝重定向、不自动重试，40 秒及 512 KiB 响应上限、最多请求 2000 输出 token，有效用量记入本会话预算及总账。`tools.web.enabled: true` 仅开放公共 HTTP(S) 网页静态文字读取，拒绝 URL 凭据、凭据查询参数、私网及保留地址，DNS 全量检查后固定连接地址，每次重定向重新核验；15 秒、最多 3 次跳转、2 MiB 响应及 8000 字正文上限，不接受压缩响应。输入及返回文字检查宿主已知凭据，错误不返回服务端正文。取消会终止本地等待和在途请求，不提供浏览器 JavaScript、登录、截图及本地文件能力。返回正文是外部不可信资料，沿用原工具结果及最终发送边界。
   - 执行主体：仅 `atMention/nameMention/question/continuation/session` 的 `reason.seq` 对应真实消息可形成 `user` 主体，并传该消息的用户身份；其余唤醒不回退最近群友。自主目标与 `commitment` 唤醒均不传借来的 `user_id/sender`，主体标签也不替代工具自身授权。
   - 自主/承诺唤醒的运行期工具面仅限本轮创建的仿真/角色/活动工具实例（排除 `simQzoneInteract/simSendPoke/simUpdateAffinity`）、已放通的 `searchInformationTool/webParserTool`，以及 `simulation.autonomousTools` 显式授权且被当前普通策略装配的三个内置图像工具（`bananaTool/googleImageEditTool/googleImageAnalysisTool`）。自定义工具即使取 `sim` 前缀也不因此获权。执行前复核群开关、人设归属、角色暂停、目标状态、共享指纹和活动版本；取消可阻止后续调用，已发起的外部动作不能承诺撤销。
   - 仿真发送工具参数无群号：目标绑定会话群，不存在"发到别的群"的路径；每回合 ≤5 条 + 每分钟 ≤8 条 + 出站令牌桶三重限速。
   - MCP：`config/mcp-servers.yaml` 手工声明，工具结果截断；custom_tools 同理。
3. **出站内容**：
   - 仿真发送先净化整个批次并检查剩余配额，再逐条复核权限/配额；同回合按完整正文精确去重，覆盖文本、引用/@混合消息与工具回复。每条确认成功后先保存预算，再发下一条；传输结果不明时记 unknown 并阻止本回合后续发送。净化/配额预检失败没有外发；真实传输无法原子回滚，不承诺跨回合 exactly-once。
   - `internalStatusLeak` 片段级脱敏（内部路径/堆栈/日志标签/协议 JSON/**凭据形状 sk-/AKIA/JWT/赋值形态**；占比>30% 或剩余<6字 heavy 整条回退）——挂在 `sanitizeFinalReplyText` 统一出口（群聊/私聊/转图路径全覆盖）+ 仿真 `simSendMessage` 发送前同源调用。
   - 工具参数形状 JSON（`looksLikeToolArguments`）主链路按行丢弃、仿真整批拒绝——同源唯一实现于 replySanitizer。
   - 违禁词出站拦截 + censor 双级词表（outboundThrottle，适配器层兜底）。
   - 聊天及仿真消息发送固定目标账号及会话，进入宿主出站限流队列的发送在放行时再次核对回合绑定。明确拒绝即使携带消息 ID 也记失败，只有确认发送才更新普通聊天的发言节流和记忆来源。
   - 仿真普通聊天由模型调用 `simSendMessage`，持久化相关最终说明经 `simFinishTurn` 转用同一发送路径。正常行动阶段被点名或正式托付回合零发送且模型输出普通最终正文时，运行时提醒一次；随后仍输出正文可能经同一 `executeTool → simSendMessage` 兜底发送。沉默声明、含沉默元话术/整条括号状态标注及本轮显式 `simDecide` 不进入兜底；`silent/deferred` 还阻止本轮发送动作。拒绝的自然说明须显式调用发送工具，内部理由不自动外发。
4. **控制台**：scrypt 账密 + cookie 会话/长令牌；配置写走 configRepository（revision 乐观锁 + 原子写 + 自动备份）；API key 脱敏读写。角色操作沿用认证入口并验证操作/记录标识，可暂停/恢复自主行动、暂停/恢复/取消目标、删除角色记忆。删除来源会清理依赖记忆并撤销依赖目标；此传播针对新角色结构化状态，不声称清空所有历史归档、模型上下文或第三方留存。
   - 独立宿主每次观察配置都重新读取完整字节，并复核目录身份、文件元数据与事务状态。文件元数据和字节均一致时复用上一次验证过的解码文本和摘要。同步权限检查结束前再做一次完整观察，文件变化立即使旧结果失效。
   - 生活线调度先在当前角色分区确认有到期订阅，再进入外部同步流程。同步在取得权限后重新读取订阅，并在外部请求及写入前复核绑定、来源权限和角色状态。
   - 后台会话摘要在智谱官方 `glm-4.5-flash` 或 `glm-5.3-flash` 请求中关闭额外推理。摘要告警包含固定操作及错误码，可包含 HTTP 状态和耗时。
   - 独立 Agent 的 `/api/workspace` 只投影已加载版本的安全元数据，逐完整绑定授权，未有可见会话的本人/连接另需目录权限。能力由服务声明、实际 handler 与权限共同决定，会话能力返回 `authorizedScopes`；前端按所选完整 scope 判断，服务端仍复核。最多各 256 条目录记录、1MiB 响应，不输出连接 URL、环境变量或凭据。管理员可见不扩大机器人的来源使用权限。
   - 独立 Core 的人物和托付管理使用中立 authority，不把 HTTP principal 或秘密传入业务模块。每次异步授权、存储及提交前后复核请求、租约、执行状态、完整目录和选中绑定。人物读取只返回当前来源场景的真实 entries；删除经真实 Store 墓碑及原子 CAS，防止迟到提取恢复。获准删除在首次存储等待前取消原账号已有来源消费者，拒绝或请求撤销不触发该取消。管理删除不宣称清除全部跨群人物资料、原始归档或第三方内容。
   - 托付管理复用 Core 正在使用的原承诺 store，取消通知在途执行且保留真实终态，不撤回已发生效果。委托记忆按完整分区严格读取和 CAS 删除；失败日志只原子删除本次获准的精确记录，保留并发新增和无归属证明的旧记录。unknown 不重建 pending、不自动补发。配置执行退休后仅认证 GET `/api/workspace` 与 `/api/config-state` 保持只读，其余已注册业务操作仍拒绝；会话/宿主撤销及秘密响应过滤保持生效。
   - 同一认证入口新增作品归档/恢复/删除、订阅暂停/恢复/移除、反思重置检查时间、共享偏好审核/撤销；操作名、id 和 payload 严格校验。作品恢复使用当前版本乐观锁。反思重置不清空每日次数，也不绕过新依据与预算限制。
   - 结构化收尾 `simFinishTurn` 由模型显式选择聊天、兴趣、拒绝、排期、等待、完成或放弃，不解析中文内容补状态。至多两条记忆与一次目标变更先在草稿验证，再以角色 revision 比较一次提交；来源、完成回执、未知字段与嵌套字段沿用实际业务校验。`throughSeq` 与引用消息在提交前核验，不能标读未展示消息。保存失败不发送提交说明，也不标读。
   - 保存成功后封住本轮；可选说明经过原 `simSendMessage` 清理、群绑定与限额。发送先保存独立 pending 回执，使用仅限此次同步公告的精确角色/目标版本许可，不能使 completed 目标恢复一般行动权限；逐条重查暂停、切人设、来源撤销、活动版本和预算。发送失败保留真实角色状态与未读，不自动重发；最终回执 CAS 冲突保留 pending 待恢复核实。同批收尾后的调用各记未执行结果。聊天工具须显式声明 `continuation=chat/interest_only`，语义真实性仍由模型负责，字段不能保证它不会说错。
   - 尝试过结构化收尾（含失败）后及最后两次工具轮仅暴露收尾工具并请求 `tool_choice: required`，本地拒绝其他工具；provider 忽略要求或未启用工具时保守结束，不扩充轮数或兜底发送。自主回合各阶段普通最终文本仍只留内部；被点名/正式托付在正常行动阶段保留既有普通文本兜底。固定协议位于人格与按需工具说明之前，动态阶段/来源置于请求末尾；记忆、网页、工具正文与人格示例不能覆盖规则。未添加客户端缓存哨兵、跨渠道缓存或新出机目的地。
   - 撤销使用独立于会话快照的 Redis 活动版本，机器人与独立控制台共享；旧 session 保存或重置不能覆盖该版本。发送、行动和后台活动复核最新版本，后续回合清理绑定旧版本的模型历史。已进入外部发送或任务执行的动作仍无法保证撤回。
   - 旧会话尚未通过实际入站绑定 bot 时，群详情返回待绑定状态和空角色活动，角色/活动管理拒绝操作；生活页不把默认机器人身份套到未绑定群。独立控制台不创建空 bot 分区或伪造入站事件。
   - 跨群偏好只共享同 bot/人设的角色观点/兴趣，模型只能提议，来源群控制台管理员逐条批准；投影不输出来源群或群友标识。正文来自原观点全文，不能自动保证无隐私，批准前必须审核正文；源记忆删除/修正或上游共享撤销会递归失效派生投影。各群运行/查看时清理派生记忆、目标、作品版本，发送前复核指纹阻止旧上下文外发。
5. **秘密与落盘**：`config/message.yaml` 明文 key（R2）；`console-users.json` scrypt；原仿真会话/记忆/好感度/初始提示词存 Redis（`shiloh:sim:*`）；新角色状态存 `shiloh:character:v1:<botId>:<personaId>:<groupId>`。身份以稳定 `personaId` 而非人设文字哈希分区；新自我笔记、情绪、作息、生活线使用同分区附属键，旧全局键保留且不自动迁移。作息单独保留管理员默认：没有分区作息时，只有 `setBy=admin` 的旧全局值可继承，旧 agent 值不继承；控制台设置会同步当前已知角色并保存此默认。生活线概览汇总当前各群角色的分区记录，不迁入旧全局生活线。令牌账本 `data/token_usage/*.ndjson` 只有计数与金额；情节记忆/归档 NDJSON 在插件 data 目录。
   - 角色状态的读取失败、坏 JSON、范围不符均抛错，不用空状态覆盖；生产 Redis 使用租约 token 校验的 Lua 原子提交/释放锁，失去锁的修改不提交。无 Lua 的内存适配器只用于同进程测试。此锁保护角色数据写入，不构成多进程执行器选主。
   - 行动先持久化 `pending`，再调用工具并保存 `succeeded/failed/unknown`；重启恢复将遗留 `pending` 标未知。未知副作用暂停目标等待核实，并阻止本回合后续外部动作，包括没有自主目标的回合；内部读取和收尾保存仍可进行，收尾不再公告。工作器最终回执在文本作品保存分支结束后提交，保存失败保留未知、禁止再次提交；已取消目标不被迟到回执重新激活。成功回执只证明运行时拿到相应工具结果或投递确认，不证明搜索内容、观点或世界事实真实。
   - 状态有界保留：保留最近 64 条一般回执和最近 16 个终态目标，保护仍被记忆/目标引用的证据来源；待确认回执也不会作为普通旧记录清掉。另有总容量限制，满载时拒绝新增；这不是永久审计归档。
   - 本批附属存储：作品 `${characterKey}:workspace`、反思 `${characterKey}:reflection`；订阅 `shiloh:character-subscriptions:v1:<botId>:<personaId>:<groupId>`，共享偏好 `shiloh:shared-self:v1:<botId>:<personaId>`（分量均编码）。作品最多 24 件/12 版/12000 字，保护其引用的回执；删除记忆会清理对应作品版本。作品区仅存文本，不提供任意文件路径或二进制资源托管。
6. **调度与预算**：仿真默认唤醒限频（2/min、12/h）+ 每群每日 40 回合 + **每日金额预算（默认 ¥5，读令牌账本）**，实际按群配置生效；超限按原预算规则停止或延后，`TURN_BUSY_LEASE` 与进程内运行集合防重复回合。自主目标复用群调度、参与边界和预算，不享受正式承诺的预算豁免；最多 3 个活跃目标，检查间隔至少 15 分钟，有期限和尝试上限。
   - 到期自主目标的唤醒优先级为 31，高于自动回复检查 30，低于开场 40、真实消息与正式托付，避免回复检查抢走目标聚焦；不改变仅@参与限制或自主执行身份。
   - 社交跟进复用原自主唤醒与权限。旧待办只用于会话接续，新待办明确记录群友欢迎在本群主动问起才可获得一次空闲检查。检查过不等于发送或完成。随机主动检查按入站序号去重，回音检查要求新的未读回应。相处习惯留在本群。最近一条确认发送的文字仅在同一 bot、人设、群和对话对象的后续回合使用，作为原主模型会话上下文，最长 500 字、仅在 48 小时内注入，服从仿真开关与来源失效规则。
   - 仿真仍按单个执行进程部署。原 QQ 群会话仅由已有账号读取。显式绑定的新会话按平台、命名空间、账号、类型及会话 ID 隔离未读、调度、限频和实际花费。撤回仅影响事件所属账号的会话，恢复只执行当前宿主管辖的地址。其他平台需要显式绑定和统一发送端口，QQ 专用工具及 QQ 原生消息段仅在 QQ 会话使用。
   - 独立 QQ 宿主通过 OneBot 正向或反向 WebSocket 核验登录账号。反向连接在 HTTP 升级前核对精确路径、Bearer token 的固定摘要、账号头及 Universal 角色，拒绝查询参数和重复活动连接；升级后仍以 `get_login_info` 确认账号，核验前丢弃事件。反向监听限 32 条 TCP 连接，HTTP 头及请求超时 5 秒，初次账号接入等待最多 15 秒；停止时关闭全部连接和监听。两种 WebSocket 单条载荷上限 6 MiB，以容纳最多两张各 2 MiB 的 base64 附图，图片自身限制保持不变。核心逐次核对绑定所属的连接和完整会话地址。收件按实例、账号和会话隔离，Redis 租约约束同实例写入，发送前复核租约与角色绑定。群消息须带真实消息 ID，确认回复的消息 ID 仅用于同一会话后续引用。群撤回按相同地址清理消息及唤醒。戳一戳须指向当前账号，按内部收件 ID 恢复，且没有可用于引用的消息 ID。OneBot 数组与 CQ 字符串均按消息段识别点名及引用，转义后的文本只作正文。读取上下文期间保留待处理唤醒，在模型调用或动作开始前领取。连接中断导致领取未能开始时保留有效唤醒，已开始的回合按动作回执结算。OneBot 断线时无法补回未送达本进程的事件。
   - 独立 Core 的仿真队列按平台、命名空间和账号隔离。升级时 Redis 租约保护旧队列的分批原子迁移，保持各账号收件顺序和回执。恢复时再核对队列账号、事件地址和绑定，撤回经已登记回执后才修改会话。平台入站引文使用同会话回查。适配器实际投递前同步复核当前绑定，当前会话的撤回会使正在等待的发送失效，其他会话仍可处理。
   - 独立宿主按当前已验证账号分别领取到期承诺及续约问询，按任务持久化地址分派。同一账号串行，各账号共用原子账本写入及执行租约，等待外部回执的账号不会占住其他账号的派发。
   - 独立仿真只为已绑定群的入站引用读取一条 OneBot 原消息，读取 ID 来自入站事件。适配器通过已验证的连接核对群号、消息 ID、账号和作者，核心继续核对绑定、撤回、原作者的记忆规则及时间。原文最多 4000 字，仅用于来源检查。会话保存引用 ID、记忆失效水位和有界文字摘录。撤回会清理引用及仅依赖它的待执行唤醒，旧摘录在隐私水位改变后失效。此路径只投影文字。
   - 独立仿真的合并转发读取按本轮可见的原消息序号定位，使用当前账号上的收件记录及 `get_msg` 核对原群、原消息及转发标识，随后只展开这个转发和它包含的子转发。总耗时、请求次数、层数、节点及模型文字长度均有上限。图片、文件等只显示类型标记。核心复核绑定、撤回及人物记忆规则，过滤禁词，保留当前回合的工具正文，历史只写查看标记。
   - 独立群仿真看图按本轮可见消息序号定位，用原群、原消息 ID、作者和时间核验直接附图或同群引用。图像来源为核验后的 OneBot 附图字节，或固定 QQ CDN 的指定 HTTPS 路径。DNS 全量校验并固定公网地址，不跟随重定向。每回合最多两次看图，每次最多两张，每张上限 2 MiB 和 1600 万像素。视觉外发前后检查绑定、撤回、群和来源隐私。二进制只在本次调用中使用，工具描述只进入当轮模型上下文。
   - 现有 QQ 仿真只从本轮可见的消息读取直接附图和转发。转发逐层读取、图片逐张下载、视觉模型发送及结果使用均复核当前回合，描述只用于当轮。
   - 仿真工具按当前宿主实际注入的执行端口装配。QQ 账号身份本身不开放戳一戳、群成员查询、空间互动、表情收藏、视频卡片或生活线；缺少对应端口时，这些工具不进入模型的工具定义。生活线须具备完整的查询、关注和退出方法，卡片还须有当前渠道的中立卡片出站端口。转发和附图按当前会话实际读取能力提供，情绪与作息工具须有对应状态更新方法。已装配工具仍受原有绑定、权限、预算、隐私及回执规则约束。
   - 独立群摘要与情节按角色和完整平台会话地址保存 Redis 有界来源、聚合及确认回复 ID，目录与详情原子比较版本提交。普通文字群未点名消息也可参与摘要，私聊不生成群摘要；私聊情节必须匹配当前已核验对话者。摘要只经显式 `midtermSummary` 后端生成，无主模型回退；`midtermMemory.enabled: false` 停止该出机链路和摘要读取。专用模型最多收到有效旧摘要和 200 条原消息的时间、作者、显示名及每条 160 字正文，无主提示词、工具或附件；全输入和输出检查宿主已知秘密，固定服务拒绝重定向，30 秒完整 deadline、512 KiB 响应和最多 8000 输出 token，HTTP 不重试，队列最多尝试 3 次。失效水位让撤回、遗忘和停用涉及的旧聚合整体不可读，即使原消息已退出有界缓冲；绑定、隐私或停止撤销在途结果。摘要与情节只进入用户资料上下文，旧人设的情节显式归因。情节时间在三种 Core 会话路径统一显示显式 `Asia/Shanghai` 日期时间，原始时间戳及权限不变，不受服务器时区影响。情节仅从已确认投递补记，失败不重发，平台投递与本地补记不保证原子；关闭 `episodicMemory.enabled` 停止补记和读取。旧插件无完整来源归属的摘要及全局情节文件保留，不自动导入。
   - 独立发布包按入口收集编译依赖和类型声明，运行依赖来自项目锁文件。固定复制范围为运行文件、启动脚本、清单、许可证和部署说明，部署配置、凭据、会话与账本使用安装环境提供的路径和存储。独立进程启动时校验发布清单与后端文件集。
   - `--check` 检查本宿主管理的绑定和所选人设，按启动配置检查所需凭据。Redis 只执行连通性检查，OneBot 使用相同的连接校验查询 `get_login_info`；反向模式临时监听配置地址，核验结束后关闭。此模式跳过执行租约和账本写入，入站事件不入队，且无模型调用与 QQ 消息发送。报告只包含实例、连接和登录标识、模式开关及绑定数量。
   - 开始 QQ 会话迁移前，核对源和目标的账号、会话、连接、角色及人设。范围为同一 Redis 数据库的已分区群委托记忆、有效且尚未被领取的固定文字承诺，以及群和好友私聊中仍有待发索引且绑定匹配的纯文字一次性提醒。预览只读并输出计数。Redis 脚本复核目标执行租约、账本锁、详情及索引，再原子移动记录和索引。已有同编号任务或并发修改使整次操作停止。已开始、结果未知、无归属或带附加动作的旧任务留在源账本。
   - `--include-group-teaching` 仅显式群迁移且目标启用群记忆时开放，读取源 data/message_archive 的本群日期文件（最多1000个/64MiB），来源和目标均停止写入或使用不可变导出。逐条核对账号、接收角色、消息ID、作者、原时间及完整顶层文字；引用、转发、截断、冲突与缺失证据保留。撤回同时核对原行和所选归档的撤回通知。旧工作流须原作者管理角色证据，群文件须本行附件。源裸群共享键只比较不删除；目标群目录/状态、人物隐私与来源登记及按完整会话持久保留的导入标记随总Lua提交。旧退出设置按本群继承一次，源群停用时不复制。删除墓碑与清空截止继续约束重跑。文件集提交前重查，仍要求离线不变来源，不声称文件与Redis原子。归档只证明接收身份，条目使用严格legacy-qq-observation分支，无人格版本或名称；只在本群作为标注的旧教学资料，不扩大通知权限。
   - `--include-agent-commitments` 允许在同一归属下迁移尚未被领取的有效仿真承诺，适用于目标宿主具备所需工具的仿真群。迁移复核两端配置和账本，任务继续按原地址和排期执行。独立宿主可为显式绑定且账号已核验的到期承诺建立空会话，会话初始化与入站串行，执行主体沿用承诺的自主工具权限。模型调用前持久化执行状态。账号或仿真暂不可用时，只释放尚未进入执行的领取，保留原排期和重试次数。已开始且结果不明的任务记为未知。
   - `--include-character-state` 仅用于同一角色的 QQ 仿真群。角色记忆和目标须保有完整依据，未接续的原消息序号、共享来源和宿主工具内容不作为目标端依据。有效修订保留必要的引用关系，旧正文只留源端。仿真检查或发送回执保留结果状态并采用固定摘要。遗留的在途外部动作转为未知，相关目标按重启规则停止自动执行。提交时核对两端角色状态和活动锁，原子保存目标状态、群调度登记、交接记录和源端目标终态。源端聊天和挂起的消息唤醒不进入此交接。目标宿主仍复核当前账号、群开关、角色绑定和执行预算。
   - 同次交接可复制当前账号、角色和群的作息及反思排期，保留反思次数与证据处理记录。原反思结果正文不复制。管理员初始提示词只有源账号、会话及绑定版本均能核验时才复制。源会话从未执行，或同一角色在独立宿主被管理员显式重置后，提示词才能在合格的入站模型调用前原子领取。领取前后复核绑定和撤回，提示词正文不写入报告或该回合历史。
   - 同一角色的作品按版本迁移，要求全部依据在目标端仍是可见的有效角色记忆或可接续回执。原聊天、共享偏好、工作器依据、待核实的在途回执及失效资料不授予复制权限。版本历史不完整时使用固定标题。源作品留存，提交比较两端作品状态、角色依据、隐私快照和活动锁。报告只统计作品和版本数量。
   - 同一 QQ 账号、角色和群的人物事实按本群原消息及匹配的索引和详情迁移，核对主体、作者和涉及者在两端的撤回、遗忘和停用约束。保留原场景和可移植性，纠正过的旧文本留在源端，目标保存去重标识。人物索引、详情、隐私约束和匹配的仿真群笔记原子提交，源索引保存已迁出事实的去重标识。旧会话序号不授予主动跟进权限。独立入口即使还没有新仿真会话，也能按账号和群处理撤回通知。仿真组装模型请求时最多补入当前对话对象的四条本群事实，去除本轮群笔记中已有的条目，附上证据类型。原始来源引文和这段直接召回结果不保存到仿真回合历史。
   - 好友私聊迁移限同一账号、角色与会话中该好友本人的自述事实，按原来源范围接续索引、详情及隐私约束。文字回合按当前发言者查询，群内允许本群来源和原本可跨群的档案，好友私聊限定本会话的本人自述。每次最多投影四条带证据类型的文字摘要，原始引用、内部标识及直接召回段落不进入会话历史。文字回合调用模型、执行工具及尝试回复前复核人物记忆失效水位，历史携带同一水位。好友撤回会持久撤销匹配的事实来源，即使迁入的原消息未进入独立宿主收件队列。
   - QQ 仿真群交接在完整账号和群地址下应用群级控制，两端任一停用即保持仿真停用，选用较严格的预算。角色自主行动暂停按原账号、角色和群生效。源令牌账本只读该地址对应的北京时间当日金额，Redis 只保存金额及回合汇总。最近一小时的收发限频只接续原会话与来源绑定版本相符的记录。提交前复核源及目标状态、活动锁和目标宿主租约，显式配置的文字模式与仿真使用同一份交接预算。
   - 同一账号、群和源绑定版本的仿真唤醒规则及活跃期定时器可以接到使用仿真的独立宿主。Redis 原子写入目标会话与调度登记，同时从源会话卸下对应定时器；已存在的目标会话阻止覆盖。定时回合按当前绑定版本、账号在线状态、群开关、预算和角色自主权限执行。原群聊天、消息唤醒与依赖旧消息的回音检查留在原分区。
   - 独立私聊默认关闭。启用后，只允许显式绑定的好友文字进入模型回合。临时私聊、命令和其他账号的消息不能触发该回合。私聊收件按接收账号排队，已确认的近期上下文按完整会话地址隔离并校验角色绑定和人设版本。好友撤回清除该会话的近期上下文，令尚未发送的旧回复失效。回复沿原会话地址发送，投递前持久化尝试标记，重启后跳过重复发送。私聊上下文保存最多 6 轮，最后一次确认后 1 小时过期。私聊工具仅用于查看和取消当前绑定下已迁入的本人待发提醒，工具正文只回原好友且不加入模型历史。
   - 本人清空、禁用及启用记忆命令独立于模型执行。入站核验当前账号、角色版本、发言者及会话，好友私聊另核验对话者。命令只接受独立文字，首次入队还检查平台发送时间。群内只影响本人在本群的记忆，私聊操作只影响同账号和角色下本人的各场景。队列按账号处理，隐私状态和命令回执原子提交，撤回或换绑会阻止未提交操作。同账号的新模型回合等待命令处理，入队时取消相关角色已有的模型请求与待投递许可。已发出请求按外部服务实际收到的数据处理，迟到结果不能继续执行。固定确认只到原会话，发送前领取确认回执，重启时跳过重发。
   - `textGroups` 可让指定账号下已绑定的 QQ 群使用文字回合。该回合只由点名或引用同会话已确认的机器人回复触发，模型上下文最多 6 轮且仅提供当前群友的历史。收件和上下文校验角色绑定与宿主配置版本。群撤回关闭对旧文字上下文的读取和提交，同时清理原仿真记录。发送前确认当前触发消息可引用并持久化尝试标记。群文字模型调用按会话限制每日次数、金额和最小间隔。
   - 群文字回合默认无工具。每群可显式放通固定文字承诺和委托记忆，每回合限一次调用，身份、账号、会话和权限由宿主提供。文字模式的已记内容只读本人，写入须来自本条原话，提醒目标固定为当前群。工具读取结果直接经出站校验，不传回模型或加入历史正文。写入前按原消息持久化尝试标记，结果未知不重复执行。已确认的本地结果可以在重启后继续投递，投递按原回执保护去重。
   - 点名、直接提问和单人延续回合默认只注入触发消息及同一群友的上下文。用工具读到的内容按实际展示的序号登记，回合引用与连续标读分别核对。近期已确认发送正文仅在同一 bot、人设、群和对话对象的后续回合使用，最长 500 字，限 48 小时，服从来源失效规则。
   - 社交跟进复用自主唤醒、暂停与预算。旧待办保留为会话接续。新待办仅在无工具审核确认触发者原话明确邀请后可获一次空闲检查，检查不等于送达。用户触发的新角色目标也核对是否为角色自己的任务，防止把社交问候转成目标排期。每回合每类至多一次，限时 12 秒、300 输出 token。截断消息、审核缺失、超时或回复格式无效不授予主动跟进。
   - 空闲后台与正常回合互斥；仅@、睡眠、暂停或预算不足时不启动后台自主活动。反思至少 6 小时、每日最多 2 次，要求 2 项未处理依据，调用前持久化预留并计群回合，记录实际 token；失败仍冷却，重启不自动重复。独立路径不带工具和发送端口，30 秒超时/取消；只写推测性观点/兴趣及等待/放弃已有目标，不改身份、权限、关系分或宣告目标成功。
7. **网络出机**（safe fetch 类）：`fetchImageBase64` 限 http(s)/2MB/15s；webParser/searchInformation 沿用各自实现的 SSRF 防护；梗提取**只喂群内消息给 LLM、不联网**。
8. **角色影子回放**（`scripts/characterReplay.mjs`）：直接装配编译后的仿真引擎，不导入宿主 adapter；每个样本新建内存存储、捕获发送，搜索、订阅更新和工作器任务固定走合成端口，不访问真实 QQ、生产 Redis、RSS 或外部工作器。正常模式调用配置中的主回合、独立反思和明确启用的隔离一致性实验模型渠道；`--social` 同样调用无工具社交许可审核，分别保留 stage、usage 和耗时；实验审核复用 memory 任务路由，元数据明确区别于生产默认关闭的独立审核路由。`--dry-run` 不读私有配置且不联网。逻辑模型调用默认最多 60 次、实际 HTTP 最多 80 次（包括兼容重试与有效降级）、整次默认 10 分钟，另有单请求和事件超时；达到限额后保留已发生结果并跳过后续事件。异步请求绑定事件和阶段，取消后未收敛则记录缺失并停止后续事件，不把迟到响应归给下个事件。证据不导出请求正文、完整人设、Authorization 或 provider 附加隐藏推理字段，按既有 scrubber 精确清理配置中的秘密/长提示文本；这不保证任意上游响应片段都不含敏感内容，分享报告前仍须核对。旧报告拒绝覆盖。`characterAcceptance.mjs` 只读取已保存证据，重算本事件前后差量并核对连续性、manifest/summary/条件；审核调用不能充当业务工具成功证据，人工表绑定候选文件 SHA256。哈希只证明本地证据一致性，不能认证报告来源。离线、缺对照、缺人工评审、真实群未观察或部署未验证时，不判阶段 7 完成。
9. **公开订阅**：最多 8 个，RSS/Atom/GitHub releases，仅 HTTPS 公网且无 URL 凭据/凭据参数。解析全部 DNS 地址并绑定已核验 IP，逐跳重验重定向（最多 3 次）；请求 10 秒、正文 512KB 上限，XML 禁用外部实体。至少 1 小时、最长 7 天；预占检查时间、失败退避、seen 128/缓存 16 条，暂停/删除后迟到结果不得提交。资料标为不可信且不授予权限，不自动代表事实。
10. **可选工作器**：管理员固定配置 HTTPS 或 loopback HTTP 网关，未启用不暴露工具；模型只能指定研究/图像/浏览任务与可见来源，不能选 endpoint、凭据、群号或文件路径。自定义桥协议 `POST /tasks` 含固定 scope、task 和 schemaVersion，`Idempotency-Key` 等于先写入的行动回执 ID；认证 token 不进入模型。30 秒超时，运行期间重复授权检查；撤销/超时以独立 2 秒 `DELETE /tasks/:taskId` 最佳努力取消，拒绝重定向、响应上限 128KB。协议不合法、异常、超时或可能已执行的 HTTP 错误记 unknown，相关目标暂停，不能盲目重试。成功文本作品完整存入本群草稿，公开仍走发送边界。外部机器实际隔离、权限与幂等由网关实现，本插件不因此提供浏览器沙箱或原生 OpenClaw API 兼容。
11. **实验性角色一致性审核**：`simulation.consistency.enabled` 默认 false；启用还须完整配置 `taskAiConfig.characterConsistency` 的 apiUrl/model/apiKey，配置缺失明确失败，不回退到 chat/memory。只读候选正文、草稿角色状态和有界可见来源，严格解析 accept/revise，不执行工具或自动补状态。记忆/收尾/反思在私有草稿校验后审核，CAS 保存前再核对权限与来源；中途文本和工具回复走同一审核入口。每回合总共最多 3 次，非收尾至多占 2 次，反思最多 1 次；每次 15 秒、900 输出 token，实际 usage 计预算。错误/超时/拒绝只阻止本次提交或发送并要求模型收尾，不能提升权限或恢复撤销来源。模型审核可能误拒或漏检，不是确定性语义保证；默认关闭时原结构、CAS、权限、去重和未知投递保护仍有效。
12. **执行结果与持久任务一致性（2026-11-11）**：
   - 仿真、承诺与普通消息共用投递回执判定：显式拒绝优先；有效非零消息 ID 才确认送达，空回执/异常/超时为未知。显式指定的媒体或承诺账号必须精确解析，不能借默认 bot 发送。工具状态读取结构化字段，正文只作业务数据；普通异常不自动重试，只有显式安全重试标记且无未知标记时允许一次。MCP 超时发出本地 abort 并保留 unknown，远端副作用无法保证撤回。
   - 承诺沿用原 Redis 详情与索引，token 锁内用 Lua 原子提交两者；领取保留索引，独立 run ID/租约区分待执行与已开始。未开始的遗留领取可恢复，执行中断后记 unknown，不自动重放；取消保留终态，旧 run 不得结算或重新排期。同群托付独立排队，不合并成聊天唤醒，以实际发送/动作回执结算。终态详情保留 24 小时、失败日志最多 20 条，不提供永久审计或跨系统 exactly-once。旧版本失去索引且无法证明结果的任务进入未知日志，需核实后重新托付。
   - 新定时承诺记录创建时的绑定归属，显式绑定记录按角色和完整会话地址分区。领取时仅处理宿主负责的平台。续约、唤醒和静态发送复核原归属及本次执行捕获的绑定版本，宿主限流后再核验一次。旧兼容承诺在会话切入显式角色后停止执行。
   - 迁入的一次性 QQ 提醒通过现有静态发送端口，群内点名原创建人，私聊直接发回原好友。使用目标的正文过滤和绑定检查，省略旧消息引用及额外动作，不发送续约或失约公告。未确认投递结果按原承诺调度的未知状态停止重发。
   - 委托记忆 bot/console 共用 Redis CAS，校验、修改和提交针对同一最新文档，损坏文档或无 Lua 能力时拒绝写。Uma 积分事务覆盖读取、校验、修改和原子保存，采用进程内队列及同机文件锁；游戏占用在同一宿主进程共享，开局、恢复、失败和结束均处理所有者，不声明多机游戏协调能力。
   - 显式绑定群的委托记忆和仿真群笔记按角色及完整会话地址读写，原兼容群键保留。控制台删除委托记忆时校验所选分区和会话。仿真切换绑定时废止旧唤醒、重试及模型上下文，群历史仍受原来源权限和账号归属约束。
   - 普通 QQ 聊天自动抽取的事实、别名、待抽取批次按角色与完整会话地址存储。抽取与反思在模型调用及受控写入前复核绑定，重启恢复按批次的原版本检查。QQ 记忆查询和清理按当前角色分区，二次确认绑定原版本，来源撤回和群级隐私限制继续生效。独立 Core 的显式群知识、工作流和教学称呼按完整会话地址维护；旧插件裸群号数据仍按原群维护且未自动导入。
   - 角色的 supersedes 链仅作历史溯源；当前有效依赖闭包不含已被修正的来源。修订使相关派生记忆/目标/作品失效，删除修订不会复活旧链；共享条目不投回来源群，也不自动赋予本轮所有可见共享来源依赖。旧 simRemember/好感度写入等待本群持久化成功后确认，scope=self 仍按 bot/persona/group 隔离。
   - 语义记忆关闭/重装会拆归档钩子、清排队定时器并 abort 旧索引/召回/embedding/rerank，迟到响应不再索引或强化；已交给 OS/上游的 I/O 仍不能回溯撤回。启动与增量按群过滤和 retentionDays 读取仍存在的归档，最多 16 条分批向量化，成功落盘后提交实际正文覆盖的消息 ID 检查点，失败保留待办。每条保留原有 400 code point 上限，窗口按完整行分块；归档已被清理的原文不能恢复。
   - 记忆纠错仅关联同 bot/group/turn 已确认发送的实际回复 ID；明确引用不回退本群最新回复，无引用只关联最新确认回复的对象。缓存有界且重启失效，缺来源时保守跳过；来源登记只证明这些 chunk 注入过该回合，不证明模型逐条采用。控制台畸形 Cookie 独立容错，整个请求解析、鉴权、路由处于异步异常边界内，错误仅影响本次请求。

### 独立语义来源与检索

- `semanticMemory.enabled` 默认关闭；启用必须显式声明完整 embedding 端点、模型和环境变量凭据，可选 rerank 也独立声明。无插件配置、主模型或隐式端点/凭据回退；关闭及 `--check` 不访问服务。
- 可信 Core 入站提供账号、Agent、完整会话地址、原作者、消息 ID 和时间。专用 Redis 来源库按宿主实例及完整作用域隔离，目录与正文 CAS 同步；最多 200 个分区、每分区 2000 条、每条 1600 UTF-16 单元、最多 90 天。不读取旧插件归档、滚动摘要或无真实接收角色的旧索引；引用/转发/附件正文及机器人消息不能冒充本人来源。群聊只同会话召回；私聊实际对话者可检索同账号、同 Agent 当前可访问群中的本人原文，其他作者在向量/关键词/重排之前即排除，不读其他好友私聊。
- 私聊跨群读取的主体与查询来源由适配器的真实作者、消息 ID 和时间确定，正文和模型不能选择他人。缺少可信查询来源时保留原同会话行为，显式不匹配则保守拒绝。来源群须仍绑定当前 Agent，并通过当前账号的机器人自身成员证据；QQ 使用 `get_group_member_info` 的 `no_cache: true`，完整地址、机器人 ID 与新鲜时间均复核。自定义适配器不支持成员读取时不授予跨群权限。平台访问在提供方请求前后、模型与投递前重新读取，来源群换绑/撤回或停机取消在途读取；来源删除、损坏和持久隐私规则也约束返回投影。重复消息 ID 使用完整来源哈希区分。
- 模型执行器在每一次实际 HTTP 派发前等待宿主的异步 `ensureCurrent`，包含生成参数兼容重试、工具规划器与文字渠道的降级；同步 `isCurrent` 同时约束最终派发。任一次异步授权拒绝即锁定该调用失效，不能因后续授权恢复而尝试其他渠道。取消可以结束挂起的授权等待，迟到放行不能继续派发。Core、独立 QQ 宿主和旧插件仿真装配均传递此复核，主回合、一致性审核、社交许可审核与后台反思分别重查其有效来源和活动范围。自定义 Core 模型宿主须在每次实际提供方请求前等待 `YTapi`、`reviewCharacter`、`reflectCharacter` 及 `judgeSocialPermission` 的第五个参数 `ensureCurrent`，不能只在第一次调用时检查。
- embedding 仅接收已核验原文或获准查询，不接收账号/作者标识；rerank 仅接收查询及有效候选原文。任一整条原文失去权限就剔除该条。混合查询缺少逐句归属且本场景存在停用时，只做本地 BM25，不发查询或重排请求；已核验私聊查询按真实对话者的本条来源检查，其他群友的停用不改变本人权限。来源授权在实际请求前及返回后重查，换绑、隐私准入、撤回和停止贯穿取消。来源删除/损坏以及持久隐私墓碑约束迟到写入、投影和使用；后台会清理失效、过期和超额原文，不承诺物理擦除备份或第三方留存。
- 索引每批 8 条、最多 2 个分区并行；来源先持久化，失败至少退避 60 秒，重启接续。目录只扫元数据，非脏分区至少 60 秒巡检。向量空间摘要改变后重新索引，旧空间向量不参加新查询。向量限制 2–4096 维、有限非零数值；来源不可被同消息 ID 重归因，状态损坏保守拒绝。
- 固定精确 HTTP(S) 端点，禁止重定向，不做 HTTP 自动重试；响应上限 1 MiB，鉴权只送配置端点，输入拒绝已知宿主秘密，提供方错误正文不写日志。Core 有界查询与索引信号贯穿 fetch 和响应体；已提交上游的数据不能保证撤回。召回资料不作为指令，投影和派生普通回复不另存为失去来源关联的历史、情节或自动群学习；显式工具保存仍受各自依赖规则约束。

### 独立 GitHub 查询

- `tools.github.enabled` 默认关闭，显式启用后在已绑定群仿真或另行显式授权的普通文字群/好友私聊装配 `githubRepoTool`；不扩大自主目标或承诺的执行权限。沿用普通工具装配策略和真人主体复核；禁用工具或撤销绑定后迟到结果不可使用。
- 唯一输入是无凭据的 GitHub 仓库根 HTTPS URL，严格检查原始拼写，不接纳转义路径、文件/issue 路径、查询参数、片段、端口或其他域名。固定 `api.github.com/repos/{owner}/{repo}` 及提交/分支/贡献者三个只读端点。基本结果必须匹配仓库身份且 `private: false`，显式非 public 的仓库拒绝。
- 默认匿名；仅可通过宿主声明的 `tokenEnv` 解析额外凭据，或由公共 API 宿主直接提供 `token`。不继承插件、环境中的其他 GitHub token 或 CLI 登录态。鉴权只放固定 GitHub API 的请求头，不附聊天/账号/角色标识、主模型密钥或 Cookie。输入和完整成功响应在字段截断前检查所有已知宿主秘密，提供方错误正文不返回或记录。
- 每个真实请求前后等待异步来源/活动授权，并检查取消与同步当前性。总期限 15 秒、单响应最多 1 MiB，取消贯穿响应体和挂起授权；任一次授权失败停止整条查询。禁止重定向与自动 HTTP 重试。基本请求失败使整条失败；可选请求失败保留已核验的基本资料并标未取得，不能将其解释为零。返回只含有界文字、来源与查询时间；分支和贡献者始终标样本，开放 issues 数包含 PR，不构成事实核实。

### 独立成员查询与点名通知

- 仅群仿真在平台适配器提供成员端口时装配 `memberInfoTool`、`mentionMembersTool`，继续使用原工具策略；`mentionAdminsTool` 保持敏感工具默认禁用，须显式放通。三个普通工具都只接受当前真人唤醒，不向好友私聊、群文字、自主或承诺回合扩权。已有 `simGetGroupMembers` 仅在实际注入中立或旧宿主成员端口时提供，沿用其原读取边界。
- 真实入站保存本条具体点名成员，工具的 `request` 由宿主固定消息 ID、原话、点名与已核验引用作者，截断正文不作为请求授权。QQ 查询沿用当前消息目标验证，真实 @、明确本人、回复或唯一姓名覆盖模型猜测；同名和长短姓名冲突要求澄清。姓名列表只暴露用户 ID、昵称、名片和角色；详细字段仅在确认单人查询后白名单返回，不复制原始 OneBot 响应或未知字段，不自动写入全局人物资料。
- 资料为可选的昵称、名片、头衔、等级、加入/最后发言/禁言截止毫秒时间、性别、年龄、地区；缺失/非法字段省略，不补零或假定“未禁言”。QQ 单人查询 `no_cache: true`，列表最多5000人且必须完整、新鲜、无冲突，校验完整账号、群和用户命名空间；名单只保留两种名字。取消、停机、换绑和来源变化阻止迟到使用。
- 点名使用当前群 ID 或唯一完整姓名，目标须有本条真实点名、回复、ID 或最长姓名依据；单独通知群主只定位唯一群主。管理员集合仅接受本条明确集合请求，排除机器人；包含群主要求原话正向包含，排除优先；排除对象歧义整批停止。沿用否定/举例/引用动作保护，不用这些检查强制选择工具。每条最多20个具体成员，发送前再次核验成员和回合。
- `AgentToolContext.sendMessage({text, mentionUserIds})` 固定原会话，不接受目标、原生段或全体点名。封闭快照拒绝 getter、稀疏数组和自定义迭代器；文字最多4000字，三种成员工具正文最多2000字。复用仿真发送队列、净化/参数拦截/违禁词、审核、完整正文去重、配额与有效消息 ID 回执；一批点名算一次发送，未知冻结后续发送，不自动重试或补发。工具结束撤销成员及发送端口，平台角色仍不提供跨服务原子授权。

### 独立 Modrinth 查询与卡片

- `tools.modrinth.enabled` 默认关闭；启用需显式独立 `translation` 模型及凭据环境变量，无主模型或旧插件配置回退。关闭时不读取翻译凭据、不联网、不启动 Chromium，`--check` 只校验。群仿真真人回合按普通工具策略装配 `modrinthTool`，普通文字群/好友私聊还须会话工具名单显式授权；不扩大自主回合或承诺的能力。
- 查询固定 `https://api.modrinth.com/v2/search`，只带关键词、排序、最多十项及版本/加载器/分类筛选；不下载模组或图标，不附聊天历史、平台身份或鉴权。严格核对项目身份、类型、数量和非负整数统计，缺失计数不补零。简介与译文是未经核实的资料，不能成为系统指令或改写权威排名、计数与链接。
- 翻译服务仅接收固定提示和本次 `{projectId,en}` 数组，凭据只在固定配置端点的请求头，不附人设、群史或工具。只接纳完整、无重复且闭合的 `{projectId,zh}` JSON 数组；失败标中文未提供并保留英文。输入、完整成功响应的原始与解析后字符串/键、交付资料检查已知宿主秘密，错误正文不进入日志或模型；有效用量归原会话账本。
- 工具总期限 90 秒，每次 API 请求最多 15 秒、每响应 1 MiB，禁止重定向与自动重试。每次外部操作及发送复核来源、活动、取消与绑定，失效丢弃迟到结果。每卡隔离 Chromium、内嵌转义 HTML/CSS、固定离线占位图标，禁 JavaScript、服务工作器与页面网络；最多 5 秒、宽 980、高 8192，超限失败不裁文。取消/超时清理迟到 browser/page，关闭失败有进程终止兜底。渲染失败只在发送前整批退为双语文字。
- 可选 `MessageActionPort.sendBundle` 和受限 `AgentToolContext.sendBundle` 只向原会话发送闭合文字/内联图片节点。最多 12 节点、每节点 4 部分、每文字 4000 字符、总文字 32000、单图 2 MiB、总图 12 MiB，复用真实格式/尺寸验证并深复制冻结。图文附完整文字供净化、词策略与审核；文字需改写则拒绝图文，避免旧图片绕过净化。
- 合并发送与文字/图片共用回合队列、配额和确认预算，一批计一次平台发送，相同净化后整批内容在本回合去重。QQ 作者固定为原账号及适配器名称，不接受模型作者、目标或原生段，只调用相应群/好友 forward API。实际写出前复核账号、连接与绑定，仅有效消息 ID 确认送达；未知结果冻结后续发送，明确失败与未知均不自动重发。不提供跨回合 exactly-once，已外发数据无法保证撤回。

### 独立显式历史查询

- `history.enabled` 默认关闭，启用后从真实入站开始保存有界顶层文字来源，按完整平台、命名空间、接收账号、Agent 与会话隔离。默认保留30天、每会话1000条；允许1–90天、50–2000条、每条4000字符，目录最多200个会话。该来源库不依赖 embedding、摘要或画像开关；不把引用、转发、合成事件、旧无来源缓存当成本人原话，不自动导入旧归档。
- `chatHistoryTool` 由当前真人请求的模型选择。群内只能检索当前群最近60条有效来源及可见长期记忆；群内禁止跨群归档。好友私聊只查经过宿主核验的本人和同账号、同Agent当前授权群中的本人原话，不读其他好友会话或其他作者。跨群先核验双侧当前绑定及机器人新鲜群成员资格，再读对应来源正文；模型不能传入来源群列表或扩大身份范围。
- 按北京时间日期整日或带时区时钟查询，每类来源默认20条、最多50条，使用各来源游标与真实记忆ID展开详情。始终标注有界覆盖和 `complete_history:false`；未命中或不可用不能解释为从未发生。索引和详情沿用同一人物隐私规则，群内跨群可移植事实隐藏原群、消息ID和原文摘句。
- 原文读取后及每次模型HTTP、兼容重试、发送和最终使用前重新核验持久隐私、撤回、来源正文与绑定。历史结果及本轮派生回复只作临时投影，不写入文字/仿真模型历史、情节、自动群学习、持久工具观察或角色记忆/目标/作品；本轮后续只允许继续查证、回复和有限安全收尾。停止、换绑和来源撤销取消在途使用，工具结束撤销工具能力；新回合重新读取和授权。开启后的本地有界原文仍按保留期管理，已提交模型或已经发出的消息不能保证撤回。

### 独立 MCP 工具

- 仅从独立宿主 `tools.mcp.servers` 显式装配 stdio、SSE 或 Streamable HTTP，不读取插件的 `mcp-servers.yaml`。网络头和子进程额外环境只通过环境变量映射提供。stdio 使用 SDK 的基本环境白名单和显式环境，不继承全部宿主环境；进程仍以宿主权限运行，不提供操作系统沙箱。命令、工作目录、固定服务及其权限由部署者控制，模型不能改写。
- 工具属于 `AgentToolRegistry.custom`，必须在原工具策略中按别名显式放通，且仅真人唤醒可执行；普通文字群/好友私聊另须会话名单逐别名授权，不扩大自主回合或承诺的能力。只发送该次工具参数，不自动附加会话、账号、人设、历史或共享教学。远端提示、instructions、资源及二进制不会提升为系统提示或自动交付；返回文字作为外部资料使用。
- 最多 8 个服务，每个最多 128 个工具、16 页，拒绝重复分页游标；连接和发现有总期限。schema 和工具元数据有界，模型 schema 兼容适配后仍按原始 JSON schema 验证参数。服务工具列表变化时先撤销旧定义和在途结果，再公布新工具；Core 从动态注册表读取，旧引用不能继续执行。
- 网络传输拒绝重定向和跨 origin 的 SSE 投递端点；允许显式配置的内网/本机服务，不能作为公共网页代理。HTTP JSON 响应与 SSE 单事件最多 1 MiB；调用最多 120 秒，返回文字最多 8000 字符。输入、工具元数据和返回结果检查已知宿主凭据，日志不打印参数、服务错误或 stderr。调用只执行一次；超时、取消、断线和未知响应按结果不明处理，不自动重试，不承诺撤销远端副作用。
- 停机、父信号、宿主配置失效、来源撤回及换绑取消在途调用；关闭清理客户端、子进程和重连定时器，迟到连接或列表不能重新装配。运行中断线可进行有界连接重试，重连不重放工具调用。启用的服务启动失败会阻止宿主启动；`--check` 与迁移预览只校验配置，不启动 MCP 子进程或请求服务。删除配置/设 `enabled: false` 后重启可停用；MCP 无独立用量接口时不虚构 token 账单。

### 独立图片工具

- 独立宿主仅在 `tools.images.generation` 或 `tools.images.edit` 显式配置时装配图片工具；模型不能改写提供方地址或凭据，无主模型回退。群仿真沿既有策略，普通文字群/好友私聊另须会话工具名单授权。自主使用仍须普通工具策略与 `simulation.autonomousTools` 同时授权。移除后端并重启停用，预检不调用图片服务。
- 图片服务只接收本次要求、所选参考图、模型和图片参数，不发送账号、角色、群或人物标识。JSON 生成、multipart 编辑及聊天图片协议均禁止服务重定向；一次任务最多 240 秒、JSON 最多 32 MiB。只在明确 400/422 拒绝 `response_format` 时去字段重试一次；不确定结果禁止自动重提，读到的有效用量逐次记账。
- 参考图为本轮可见的 QQ 附图或公开 HTTP(S) 图片，最多 10 张、合计 40 MiB。附图原群、来源 ID、作者、时间、隐私、撤回与绑定检查沿用原媒体路径，无视觉后端也可交给编辑工具；不向主模型暴露字节。公共图片可含 CDN 签名查询参数，禁止 URL 用户名密码、私网及保留地址，DNS 全量检查并固定实际连接，逐跳复核，最多 3 次跳转、15 秒、20 MiB；只发送固定 GET/Accept 头和 identity 编码，不带宿主 Auth/Cookie。
- 只交付一张通过标准 base64、实际图片头和画布检查的 PNG/JPEG/WebP/GIF，最大 20 MiB、单边 16384、总像素 64*1024*1024。生成字节、成图 URL 和提供方正文不进入主模型。输入和结果拒绝已知宿主凭据。
- `sendImage` 与旧文字工具回复共用当前回合发送队列、配额、预算和有效回执；并发调用不会绕过配额。Core 通过平台无关动作和底层队列后的当前性检查交付。结果未知会冻结本回合后续发送；停用、来源撤回、换绑、工具结束和停止使后续读取及交付失效。已经发出的提供方请求或平台发送不能保证撤回。新增工具时限可到 240 秒，缺省仍为 45 秒。
- 平台附图读取可接受 `MessageImageReadOptions.signal`，从工具或视觉回合贯穿 Core、OneBot `get_msg`、来源授权等待、DNS 与 HTTPS 响应体；取消会停止当前等待和下载，不再读下一张。Base64 与 URL 附图的授权检查即使挂起也不阻塞取消，迟到授权不能继续取图；底层权限查询及原生 DNS 不承诺撤销。OneBot 同时保留五秒总期限，并每 25 毫秒复核连接及调用方当前性，将换绑或来源失效转为取消。完成后清理轮询与取消监听，不把中止当作成功；已经发送的网络请求无法保证撤回。

### 独立文件来源与文档只读解析

- 显式启用 `tools.excel.enabled: true` 后，群仿真按原策略装配 `excelWorkbookTool`，普通文字群/好友私聊另须会话工具名单授权；不扩展自主或承诺执行面。群文件目录端口仍只授予群会话，好友仅可读核验后的当前/引用来源或显式公共 URL。保留群文件列表、工作表列表、单元格、区域和查找五种读操作，不提供创建、修改或上传。工具可用固定扩展名筛选候选，模型不能传平台文件 ID、busid、下载引用或宿主路径。
- 文件来源由 Core 绑定本轮真实用户请求。顺序为真人原文中的精确显式 URL、当前附件、核验后的引用、本人最近 30 条/30 分钟附件、当前群文件仓库；歧义要求准确文件名/目录或可见 sourceSeq。消息文件以 get_msg 重读验证会话、作者、时间、撤回及原始附件序号；直接文件和引用文件保持稳定选择。群上传 notice 不伪造消息 ID，缺消息锚点的上传只能由重新列出的群文件证据确认。
- 群文件目录和下载均固定账号、namespace、会话和当前角色绑定，仓库引用留在适配器内部；下载前重新列目录精确匹配 ID、busid、名称、路径、大小、上传者和时间。目录受层数、文件夹数和文件数限制并明示截断。缺上传者/时间或无法证明人物隐私权限的条目不供读取，不用文件名或模型参数补造来源。
- 公开读取工具须声明 `dataPolicy: 'ephemeral'`；未声明工具不提供文件端口。声明工具在执行前进入本轮临时资料模式并跳过持久行动回执；每次文件/list 读取在接触内容前也置位；失败结果同样临时。目录/文件来源在后续每次模型 HTTP、兼容重试和发送前重新核验，换绑、停用、撤回或删除使迟到文本失效。仅允许继续查询、当前会话回复和不保存资料的收尾；正文及派生回答不写工具正文回执、观察器、agentHistory、人物记忆、群学习、情节、目标或作品。入站只保留有界文件名称和数量，不保留资源 URL、平台文件引用和 bytes。
- 下载最多 12 MiB、20 秒、3 次重定向；每跳核验全部 DNS 地址并固定实际连接，拒绝非公网、URL 用户名/密码、压缩响应和超限流。只有经核验原始平台证据或真人精确提供的 URL 可以使用其签名查询参数，不带宿主 Auth/Cookie。取消/授权失效停止后续步骤，传给工具的只有受控名称、来源枚举和内存字节，不含平台引用或 URL。
- ZIP 实际解压预检、ExcelJS 解析、查询和 12000 字输出格式化全部在固定入口工作线程中执行。默认一个运行、四个排队、15 秒总期限，宿主只能在固定上限内调整；线程 heap 256 MiB，取消/撤权/超时 terminate 并等待退出。压缩最多 12 MiB、2000 条目、展开总量 64 MiB、单条 16 MiB、sharedStrings 8 MiB/100000 项，另限制真实单元格、行列和合并面积；拒绝加密、路径穿越、重复项、DTD 和超预算 XML。资源限制不是操作系统沙箱。
- 沿用原查询函数和公式缓存语义，不计算公式、不执行宏、不获取外部公式；无缓存要求 Excel/WPS 重算保存。支持 `.xlsx/.xlsm/.xltx/.xltm`，旧 `.xls/.xlt` 要求另存。没有跨账号工作簿缓存，不声明样式、宏或文件往返无损；显示值保持 ExcelJS cell.text 的既有语义。

- 私聊和群文字学习须另设顶层 `memorySystem.enabled: true`，默认关闭。只从确认送达的普通文字回复收集用户来源，沿用 90 秒静默或 6 条批量节奏；设置只接受开关、0–3600 秒防抖和 1–40 条批量上限。收件确认与学习入队可恢复但不会盲目重发；来源与模型结果有界保存，CAS 原子更新最多 200 个缓冲，每个最多 60 条、每条 4000 字，结果先保存再写事实，同一结果可幂等重放。失败最多 3 次自动尝试，保留耗尽记录。引用、转发、工具结果和低信号资料不学习。私聊的会话 ID、真实对话者和原始时间不能由模型或房间 ID 代填，私聊事实强制本会话本人可见。换绑、换人、撤回、隐私变更、关闭功能或停止时拒绝迟到结果，每次写入传递最终提交保护。

## 四、已知残余风险

- **R1** 出站拦截是启发式（正则形状），精心构造的绕过可能漏拦；heavy 兜底保证"宁可少说不可泄密"。
- **R2** `config/*.yaml` 中 API key 明文存放（同机读权限者可见）。
- **R3** `custom_tools/` 与 MCP server 是任意代码执行面，信任边界=部署者本人。
- **R4** 上游 provider 对发过去的内容的留存与使用不受本插件控制。
- **R5** 仿真放通的既有工具（toolPolicy open 默认面 / extraTools 追加）继承其自身实现的安全性（如搜索的关键词出网）；敏感工具（禁言/撤回/送礼/抢红包/QQ空间/改名片/@全体管理/reminder）RESTRICTED 默认禁，解禁须显式 `toolPolicy.allowTools`。
- **R6** 同一外部动作与 Redis 回执写入不能组成跨系统事务。超时、中断或回执丢失可能产生未知结果；暂停目标和未知标记降低重复执行风险，不能证明外部动作未发生，也不提供自动撤销。
- **R7** 实验语义审核仍有漏检，且推理/传输超时或输出截断会保守阻止正常消息；目前默认关闭，固定用例通过也不能替代多轮实模与人工验收。

## 五、发布前检查清单

1. `npm run verify:phase` 全绿（typecheck + boundaries + 全量测试 + 控制台前后端检查）。
2. 改过出站/工具边界 → 构建后运行 `node --test tests/replySanitizer.test.js tests/simSilentDeclaration.test.js tests/characterRuntime.test.js`；再以 `tsconfig.backend-tests.json` 编译领域测试并运行对应的 `simulationDomain` / `characterState` 用例。
3. 新增数据出机目的地 → 同步「数据出机清单」表。
4. 改过仿真安全相关 → 冒烟（假 Redis/假模型）确认零外发路径无回归。

## 六、改动检查单（每个涉及边界的 PR 自问）

- 新工具进入哪个白名单？仿真回合要不要放通？
- 新的数据离开本机了吗？进清单了吗？能关吗？
- 新的出站路径过 `sanitizeFinalReplyText` / `simSendMessage` 的脱敏与拦截了吗？
- 新的定时器/后台任务有预算与频率上限吗？


## 独立 Core 操作与错误日志

独立宿主默认在 dataDir/operations 保留有界私有 NDJSON 诊断，仅含归属引用、traceId、阶段、静态码、结果、耗时、HTTP 状态及安全异常类型。禁止正文、参数、原始异常/堆栈、provider body、URL 与临时资料入日志；已知秘密整行检查失败时写固定脱敏替代事件。写入 fsync 后才确认，日志失败通过安全 stderr/health 显式报告，禁止以日志失败为由重发业务动作。保留期、总文件数和大小见 agent-bindings.md 的 logging 配置；公共 journal 的跨进程唯一 owner 由宿主租约负责。

真人失败说明向原触发会话发出，模型仅接收安全失败结论且无工具；说明模型不可用时短提示附查询编号。沿用发送、绑定、隐私及撤回检查，未知投递后禁止补发；说明不写长期记忆。该说明会向既有获准模型发送 persona 与安全失败分类/结论，不新增外部服务目的地。
