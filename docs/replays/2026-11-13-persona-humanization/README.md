2026-11-13，使用生产配置里的真实模型渠道，在服务器隔离进程运行编译后的机器人。合成群消息、独立内存存储、捕获投递，跨天使用回放时钟推进。生产 QQ 发言和生产存储写入均为 0。隔离候选采用生产人设配置，替换身份、语气、说话习惯、边界、备注、反应和示例七项。完整对照的基线是任务开始时冻结的本地源码（包含当时已有改动），生产实例的版本是 8cfd3d1。基线不冒充生产二进制。

## 普通聊天

[基线](base-ordinary.json)和[候选](candidate-ordinary.json)均走线上 `glm-5.3-flash`，每侧两轮，四个请求均 HTTP 200，四轮结构检查通过。两边均在追问中明确没有进食。候选明确是机器人，但“今天这群里唯一的饭”超出给定材料。样本只用于验证这条身份和身体经历路径。

## 匿名对话评审

独立子代理只读打乱顺序后的[匿名对话](anonymous-samples.json)，提交逐组判断后再[揭盲](review-key.json)。这是模型辅助的文本评审。候选 5 胜、1 负、1 平。

| 场景 | 匿名判断 | 揭盲后依据 |
| --- | --- | --- |
| 语气和误会修复 | A 胜 | 候选贴合具体成绩，认真被问身份时直接回答。基线仍抛出租金梗。 |
| 安慰和关系分寸 | B 胜 | 候选在对方明确求建议后给出完整回答，守住了称呼和倾听要求。基线末句停在“把”。 |
| 饼干和并行话题 | 平，双方均有失误 | 双方都把另一人的烤箱牵进饼干对话。候选未 @ 那人，但 403 的原因判断过强。 |
| 碰巧聊到再问 | B 胜 | 候选可见输出在两个检查中均安静，等群友回来说进展再接。内部仍有一次误判主动标记并调用主模型。 |
| 明确邀请主动问 | B 胜 | 基线这次确实主动问了一句，候选有回复但未建立有效待办，后续还误判布展提前完成。最终版另有定向复测。 |
| 兴趣和观点 | A 小胜 | 两边都保留了对折痕的偏好。候选提出用后续卡关反馈验证，仍有“设计本身没毛病”一类过度确认。 |
| 已散场时安静 | B 小胜 | 候选两次空闲检查均无发言，基线空闲时补发告别。 |

胜负只适用于这七组文本。自然度评审不替代工具回执、时钟与行为验收。

## 跨天定向复测

[明确邀请的两次复测](final-welcome.json)均先保存有许可的待办，隔天在群里只问一句、无 @，随后标记待办完成。无人回应时重启再检查，两次均未发送或调用主模型；各有一次独立反思调用。实际采用的问句包括“布展该收尾了吧，摆得怎么样喵”和“喂，到点了，纸灯展摆得怎么样了”，后者仍略像提醒。

[碰巧聊到的两次复测](final-quiet.json)均保存为无主动许可，两个空闲检查均不发言，后一个检查也不调用主模型。对方回来后，两次都收掉了待办，一次正常承接，另一次在成功更新好感度后，旧回执缺少成功字段导致回复被阻止。保留该原始失败，随后修复好感度结构化回执。时间文本增加了本轮北京时间日期，避免跨天继续把历史中的“明天”当成当前日期的明天。

[好感度回执修复后的复测](receipt-quiet.json)中，对方报面试结果时收到一条正常回复。此次仍有一轮误将“碰巧聊到”记录为主动许可，第一次空闲检查调用主模型时超时，降级模型未发言。这个样本不能证明该措辞已能稳定识别。好感度和相处习惯同时写入后能继续发送，由定向工程回归独立验证。

后端冻结源码全量验证 3370 项，3368 通过、0 失败、2 项 Chromium 截图跳过。最后一处好感度回执调整单独重新构建，3 项相关回归全通过。全量前一次曾因为测试中途主目录源码改变，被编译产物校验拒绝，随后在冻结目录重跑通过。完整群聊对照、跨天定向回放和最后的回执复测使用不同的候选构建，分别保留哈希。生产实例仍是 8cfd3d1。
