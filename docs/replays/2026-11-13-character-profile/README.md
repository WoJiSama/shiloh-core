## 下一轮复用

- 继续使用本轮的语气、观点、小习惯三组样本，再加入群友情绪低落、不同熟悉度、别人已经给出答案、认真对话转回闲聊。核对回复实际内容和分条，尤其是重复开头、为了续聊添加的追问。
- 检查偏好在两个话题、两个日期间如何延续。区分人设明确设定、根据新资料形成的判断，以及本群长期使用的小习惯。重点看能否自然说出喜欢哪一点，也能说明什么时候改变想法。
- 有真实群反馈后，在后台补按时间或来源筛选、兴趣更新轨迹以及修订前后查看。评审以真实行为和保留的依据为准。
